# 不要买——辱华 / 不尊重中国

> 口径：分四类，按严重程度排：
> 1. **硬伤（分裂国家）**：T恤/官网把香港、澳门、台湾列为"国家"。
> 2. **政治站队**：公开声明抵制新疆棉花 / 配合西方"强迫劳动"叙事。
> 3. **侮辱革命领袖 / 伤害民族感情**：广告恶搞毛泽东、引用达赖言论等。
> 4. **舆论争议**：被中国消费者广泛认为区别对待、不尊重中国市场，但不一定违法。
