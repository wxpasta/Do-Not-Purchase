# 怎么选——奶制品选购指南

> 市面上那么多奶产品，很多人不知道怎么选。这篇教你 3 步挑到好牛奶，避开"假牛奶"。

## 一、先搞清楚：你买的是哪种奶？

| 类别 | 国家标准 | 配料表 | 特点 |
|------|----------|--------|------|
| **巴氏杀菌乳（鲜牛奶）** | GB 19645 | 只有"生牛乳"三个字 | 冷藏，保质期短（3-7天），保留更多活性营养 |
| **灭菌乳（纯牛奶）** | GB 25190 | 只有"生牛乳"三个字 | 常温，保质期长（6个月），适合囤货 |
| **调制乳** | GB 25191 | 生牛乳+糖+香精+维生素等添加剂 | 加了糖和香精，不是纯牛奶 |
| **复原乳** | — | 写着"乳粉""水" | 用奶粉冲的，不是鲜奶（2025.09.16 起常温奶全面禁用复原乳） |
| **乳饮料/牛奶饮品** | — | 水+牛奶+糖+香精 | 大部分是水，牛奶含量很低，不算奶 |

## 二、挑牛奶的 3 个硬指标

1. **配料表只有"生牛乳"三个字**——出现"乳粉""糖""香精"就不是纯牛奶
2. **蛋白质 ≥ 3.2g/100ml**——及格线，优质产品可达 3.6g 以上
3. **钙 ≥ 100mg/100ml**——正常牛奶的钙含量

## 三、巴氏奶 vs 常温奶，怎么选？

| | 巴氏奶（鲜牛奶） | 常温奶（纯牛奶） |
|---|---|---|
| 杀菌温度 | 72-75℃ | 135-150℃ |
| 保质期 | 3-7天 | 6个月 |
| 储存 | 必须冷藏 | 常温 |
| 营养保留 | 更多活性菌、维生素 | 稍微损失一些 |
| 口感 | 更接近鲜奶 | 稍微淡一点 |
| 适合谁 | 每天喝、能逛超市的人 | 囤货、送人、不方便冷藏的人 |

## 四、常见品牌怎么选

### 巴氏鲜奶（冷藏柜里的）
- **三元（北京）**：北京本地品牌，巴氏奶口碑好
- **光明（上海）**：华东地区巴氏奶龙头
- **味全（全国）**：冷藏鲜奶做的不错
- **每日鲜语（全国）**：高端巴氏奶，蛋白质 3.6g 以上

### 常温纯牛奶（货架上的）
- **伊利金典 / 蒙牛特仑苏**：高端常温奶，蛋白质 3.6g 以上
- **伊利纯牛奶 / 蒙牛纯牛奶**：基础款，蛋白质 3.2g 左右
- **三元小方白 / 光明优加**：性价比高
- **德亚 / 安佳（进口）**：进口常温奶，价格稍贵

### 避坑：这些不是"奶"
- **营养快线 / 酸酸乳 / 优酸乳**：乳饮料，大部分是水
- **早餐奶 / 核桃奶 / 红枣奶**：调制乳，加了糖和香精
- **核桃奶 / 花生奶**：植物蛋白饮料，不是牛奶

## 五、酸奶怎么选？

- **看配料表**：第一位应该是"生牛乳"，不是"水"
- **看蛋白质**： ≥ 2.9g/100g 才是真酸奶
- **看"灭菌"还是"活菌"**：
  - 活菌型酸奶：冷藏，有活性益生菌
  - 灭菌型酸奶：常温，没有益生菌，但保质期长
- **避开**：风味酸奶（加了很多糖和果酱）、乳酸菌饮料（大部分是水+糖）
