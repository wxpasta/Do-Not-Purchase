# 吉林省监厅通告速查：点名到牌子的那些

> 口径：只收**吉林省市场监督管理厅食品抽检通告、省级产品质量监督抽查通告、属地核查处置通告**里点名到**品牌/企业/商品**的条目。
> 一句话：吉林跟别省不一样——**儿童服装、童鞋、校服抽查基本都合格**（2026 年那期童鞋 13 批、童装 16 批、校服 26 批全部合格），问题集中在**酒类、汽水、酱卤肉、酱油**和**纸尿裤**。

## 一、食品（省厅通告点名）

| 牌子 | 什么东西 | 结论 | 一句话原因 |
| ---- | ---- | ---- | ---- |
| "百年公主"（公主岭市三奇酿酒） | 茶缸酒（白酒） | 不能买该批次 | **酒精度**不符合标示（度数不够，等于变相掺水） |
| "春城迎宾"（长春市百粮春酒业） | 春城口杯酒 | 不能买 | **纽甜**不合格——甜味剂超范围使用，白酒里不该有 |
| "莫小乔"（通化市莲池葡萄酒） | 冻梨味汽水 | 不能买 | **酵母**超标，说明杀菌不彻底，会继续发酵胀瓶 |
| "岩泉"（安图千盛食品） | 牛板筋（酱卤肉制品） | 不能买 | **菌落总数**不合格，熟肉制品卫生控制不到位 |
| 谷正香酱菜厂（白城洮北区岭下镇） | 老式酱油 | 不能买 | **氨基酸态氮**不达标，属"掺水/发酵不足"的质量指标问题 |
| 泰盛食品厂（松原宁江区） | 老式面包 | 不能买 | **糖精钠**不合格（检出甜味剂，20 袋货值 211 元已售完） |
| "工人村酒"（松原经开区丽锋酒坊） | 黑糯玉米酒 | 不能买 | **酒精度 + 邻苯二甲酸二正丁酯（DBP）**双不合格，塑化剂来自塑料容器/管道 |

## 二、用品（省级监督抽查）

| 商品 | 抽查规模 | 结论 | 关键点 |
| ---- | ---- | ---- | ---- |
| 童鞋（2026 年 48 类专项） | 11 家销售者、13 批次 | **全部合格** | 这期没点名，说明吉林童鞋端相对干净 |
| 儿童及婴幼儿服装（2026 年 48 类专项） | 14 家销售者、16 批次 | **全部合格** | 同上；但样本量小，别当"全域安全"结论 |
| 校服（2025 年三季专项） | 13 家、26 批次 | **全部合格** | 吉林校服这一期没查出问题 |
| 儿童学生用品（2025 年三季专项） | 38 家、66 批次 | **3 批次不合格（4.55%）** | 已知一例：通化同视隐形眼镜售"贴心 TieXin"老视镜（XZ8106），**标志**不合格 |
| 纸尿裤（片、垫）（2026 年 48 类专项） | 84 家、94 批次 | **3 批次不合格** | 具体品牌在通告附件名单里，母婴店买纸尿裤建议核批次 |

## 三、历史条目（跨年参考）

- 吉林省工商局流通领域抽查：**户外服装、鞋类 50 组样品 24 组不合格**（速干性、纤维成分、色牢度等），**LI-NING** 在名单内。详见 [lining.md](../02-clothing/lining.md)。

## 四、怎么用这份清单

1. **吉林买酒看两个指标**：酒精度（是否与标示一致）、塑化剂（DBP）。散装白酒、小酒坊是重点。
2. **汽水看酵母**：酵母超标会胀瓶、爆瓶，别买瓶身已鼓的。
3. **酱卤肉看菌落总数**：牛板筋、酱牛肉这类即食熟肉，开袋有异味直接退。
4. **酱油看氨基酸态氮**：低于 0.4 g/100mL 基本是"稀酱油"，别为"老式""手工"加价。
5. **儿童用品这省相对稳**：2026 年童装童鞋、2025 年校服抽查全合格；但样本量小，仍按 GB 31701 A 类、3C 这些硬指标买。
