# 广东 / 广州监管通告速查：点名到牌子的那些

> 口径说明：没有"广州省监局"这个机构，这里按两级来做——**广东省市场监督管理局（省级抽检通告）** + **广州市市场监督管理局（召回、校服专项）**。
> 一句话：广东食品端不合格集中在**饮用水铜绿假单胞菌、凉果/菜干铅超标、酒精度虚标、防腐剂比例之和**；儿童端最该记的是**广州备案召回的三款童装童鞋**和 **2025 年广州校服 7 批次不合格**。

## 三、广州：2025 年校服专项抽查

- 共监抽 50 家，**7 批次不合格（2.73%）**；剔除纯标识问题，**实物不合格 3 批次（1.17%）**，不合格项是**纤维含量**。
- 判定不合格的市场主体：**广州京宏服装贸易有限公司**（多批次，含纤维含量+标识）、**爱丁洋（广东）科技实业**（园服下装，纤维含量）、**广州市南沙区港湾街道港湾幼儿园**（园服，标识）、**广州启航文教用品**（童装上衣，标识）。
- 渠道分布：生产渠道 5 批次（实物 2）、流通渠道 1 批次（实物）、**学校渠道 1 批次（纯标识）**——说明校服问题主要在**生产端**，不是学校采购环节。

## 四、广东这几个"高频雷"

1. **瓶装/桶装水**：铜绿假单胞菌是广东通报常客（恒大冰泉、观音山都在列），买水看批次与桶底回收痕迹。
2. **凉果、菜干、梅干菜**：铅超标集中在这类传统干货，散装摊尤其要看来源。
3. **蜜饯类防腐剂**：单一种不超，但"比例之和"会超——甘草榄、油柑这类就是典型。
4. **白酒/米酒"酒精度不符"**：广东多起，散装酒、抖音小店款慎买。
5. **炸货看酸价、饼干看过氧化值**：说明油反复用或存太久。
6. **儿童用品认召回批号**：广州备案召回的三款（连体衣 80/48、mr. baby 26–35 码、2021 批儿童皮鞋）直接别碰。
