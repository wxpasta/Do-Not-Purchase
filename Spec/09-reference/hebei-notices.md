# 河北省监局通告速查：点名到牌子的那些

> 口径：只收**河北省市场监管局省级监督抽查、省/市/县局核查处置通告与处罚决定书**里点名到**品牌/企业/商品**的条目。
> 一句话：河北的问题有两头——**食品端饮用水（铜绿假单胞菌、耗氧量）和玉米粉（黄曲霉毒素）反复出问题**；**用品端低价童装、校服"纤维含量虚标"是主流**（标 100% 棉，实测掺化纤）。

## 四、河北这几个"高频雷"

1. **桶装/瓶装饮用水**：铜绿假单胞菌、耗氧量是河北通报的常客，多是小水厂。买水看生产日期、看桶底是否有回收划痕。
2. **玉米粉、玉米面**：黄曲霉毒素 B1 是玉米制品的头号风险，散装玉米面尤其要看生产日期和储存条件（受潮就产毒，加热也去不掉）。
3. **月饼、糕点**：霉菌、菌落总数，河北月饼小作坊多，散装月饼别买"提前一个月就摆出来"的。
4. **校服、低价童装**：纤维含量虚标是绝对主流——标"100% 棉"实测掺涤纶。给孩子买校服、几十块的童装，认吊牌成分 + GB 31701。
5. **童鞋**：重金属 + 邻苯，河北本地鞋厂也有被查的（新乐舒达），买河北产童鞋照样要看检测报告。
