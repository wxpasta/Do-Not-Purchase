# 无印良品（MUJI）：哪些不能买

> 口径：只收**市监局行政处罚决定书、省局监督抽查通告、企业主动召回**里点名到具体产品或款号的条目。
> **先分清两个"无印良品"**：一个是被抽检点名的日本良品计划在华公司**无印良品（上海）商业有限公司**；另一个是**无印良品（北京）生活科技有限公司（北京棉田旗下 Natural Mill）**，两家长期打商标官司，床品、毛巾类的中文"无印良品"商标权在北京棉田一方。下面分开写，别混着骂。

## 一、无印良品（上海）＝ 大家熟悉的 MUJI

| 产品 / 款号 | 问题与事实 | 结论 |
| ---- | ---- | ---- |
| 全棉四件套（被套） | 南通市崇川区市监局 崇市监处罚〔2025〕X00079 号（2025.10.09）：**断裂强力**不符合 GB/T 22796—2021，**复检仍不合格**；进货 85.08 元/套、售价 258 元/套，罚没合计约 606.84 元 | 不能买该款（四件套先摸克重和密度） |

## 三、食品：日本本土召回，代购渠道有风险

- 2025.08 日本良品计划自主召回 **4 枚装栗子铜锣烧**（保质期至 2025.09.22 / 09.26，约 3000 个），原因：部分原料可能混入异物。
- 该商品**不在中国大陆门店销售**，但多个电商平台有代购在售——看到同期批次别买。

## 四、MUJI 该怎么买（按品类给结论）

1. **服装**：深色、荧光色款的色牢度是历史弱项（童装罚过 35 万）；买深色先看吊牌是否标 GB 31701 A 类（婴幼儿）/B 类（贴身），能当场用湿白纸擦一下更好。
2. **床品四件套**：被套断裂强力不合格说明面料密度不够，用几次就撕口；认 GB/T 22796—2021，摸克重、看密度，别只看"水洗棉"文案。
3. **蚕丝被 / 羽绒被**：认准生产企业，别只认 logo；MUJI 的床品多为南通、浙江代工，和专表 [silk-quilt.md](../03-living/silk-quilt.md) 里那批"塞头、增重、短丝"是同一个产业带的风险。
4. **食品**：只买国内正规渠道、有中文标签的；代购的日本本土批次出了召回你收不到通知。
5. **售后**：外卖/即时零售渠道曾被认定"不支持 7 天无理由"违法，**大件还是官网或门店买**，留好小票。

## 五、别一刀切

- MUJI 被罚的多是**单款、单批次**（四件套、两款童装、某批次产品），不是全线不合格；它的优势品类（文具、收纳、香薰基础款）没有被点名记录。
- 罚没金额普遍很小（四件套案仅 606 元级、外卖案 5000 元），说明**违法成本低于收益**，别把"还在卖"当成"没问题"。
- 日本本土召回不涉及大陆门店，但**代购链条不受召回保护**，这是真实风险点。
