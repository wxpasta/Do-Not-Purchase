# 京东京造（J.ZAO）：哪些不能买

> 口径：只收**消协比较试验/约谈通报、市监局抽查、黑猫投诉实录**。
> **先看懂它是什么**：京东京造是京东的**自有品牌**，不是自建工厂——按京东的标准找代工厂生产，品类横跨家电、家纺、食品、宠物、家具。所以它的风险特征是"**单个 SKU 出事，不是全品类出事**"，而且**越带电、越讲功效、越是大件，越容易翻车**。

## 一、消协点名（官方口径）

| 品类 | 事实 | 结论 |
| ---- | ---- | ---- |
| **除醛凝胶 / 除醛类产品** | 京津冀三地消协 2026.04 比较试验后约谈相关企业；通报明确：**除醛凝胶类产品中，山山、京东京造等品牌"仍存在相关问题"**，未按要求整改到位 | 不能买（除醛凝胶、除醛仪整类都别信） |

同次试验的底数：抽检 **50 批次测醛仪，没有一款能做到"精准检测"**——这一类产品整体是"心理安慰品"，不是京东京造一家的问题。

## 三、所以哪些不能买

1. **除醛凝胶、除醛仪、测醛仪**：整类不买，消协已点名且整改不到位。
2. **充电宝、电池类**：便携电源是电芯安全重灾区，出了事是火灾级损失；要买认一线电芯品牌的自有型号。
3. **净水器、滤芯类**：宣传"6.5 年长效"这类夸张寿命的，直接跳过；滤芯是长期耗材，售后跟不上等于白买。
4. **大件家具（沙发、床垫、学习桌）**：代工 + 大件物流 + 安装，出问题退货极难；这类宁可线下看实物。
5. **"功效型"家纺/贴身品**（抗菌、远红外、胶原蛋白等）：宣传指标多、可验证性差，出问题只能靠嘴仗。

## 四、相对可以买的部分（别一刀切）

- **深圳消委会 2026 年儿童洞洞鞋比较试验**：15 款样品中，被检出鞋花化学物质超标的是 **balabala、abckids、朴西**，京东京造在样品之列但**不在不合格名单**——说明它在低风险标品上有基本品控。
- 纸品、收纳、基础家居耗材这类**无电、无化学功效、可肉眼验货**的标品，自有品牌性价比优势明显，风险主要在"用料一般"而不是"安全"。
- 判断法：**出了问题会不会烧起来、会不会进嘴、会不会搬不动**——三个"会"就别买京造，三个"不会"可以买。

## 五、五条买法

1. 带电产品先查 **3C 认证编号**（认监委官网可验），充电宝看额定能量与电芯品牌。
2. 参数型承诺（净水年限、抗菌率、除醛率）一律要求**检测报告编号**，拿不出来就是话术。
3. 大件下单前问清：**谁安装、谁上门取件退货、运费谁承担**，三条含糊就别买。
4. 保留商品页截图（宣传承诺是维权依据，京东自有品牌尤其适用）。
5. 别把"京东自营"等同于"京东自己造"——它也是代工，出事照样要你走售后流程。
