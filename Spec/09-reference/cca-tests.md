# 消协比较试验：点名到牌子的"不能买 / 少买"

> 口径：只收**中消协及省市消协比较试验报告**里点名到品牌、且结论是"未达到标准明示要求 / 存在安全风险"的条目。
> **先说清一件事**：比较试验≠行政处罚，报告写明"检测结果仅对样品负责"。所以下表的"不能买"= 这一款样品实锤不合格；"少买"= 性能或标识有短板，同品牌其他型号未必一样。

## 一、中消协（全国）点名

### 1.1 儿童羽绒服（2026.01 发布，30 款）

| 品牌 | 问题 | 结论 |
| ---- | ---- | ---- |
| 贝肽斯 | 绒子含量、绒丝+羽丝均未达 GB/T 14272—2021 明示要求（绒丝+羽丝 11.7%，限值 10%） | 不能买 |
| PUMA® | 同上，绒子含量实测 9.9%（偏差 −7.1），绒丝+羽丝 12.0% | 不能买 |
| 雅鹿 | 同上，绒子含量偏差 −11.6%，绒丝+羽丝 16.3%（全场最高） | 不能买 |
| Dickies | 吊牌**未标注绒子含量**，无法核对填充物等级 | 不能买 |
| dave&bella 戴维贝拉、TEENIE WEENIE KIDS、鸭鸭、ZOSEE/左西、CANADA GOOSE | 模拟穿着后气味"淡但能明显察觉" | 少买（气味敏感者避开） |

同一报告的反向事实（别一刀切）：30 款样品**纤维含量、甲醛、pH 全部合格**；羽绒中烷基酚（AP/APnEO）**全部合格**；29 款无刺鼻异味。

### 1.2 儿童书包（2026.11.26 发布，25 款）

| 品牌 | 问题 | 结论 |
| ---- | ---- | ---- |
| 自然鱼 | 可触及塑料件（轮子粉色塑料）**邻苯二甲酸酯超限值** | 不能买 |
| Uniker 优丽克 | **缝合强度不足**，缝线易脱开、部件易脱落 | 不能买 |
| ZUONU | **震荡冲击**性能不理想，测试中提把处开线 | 少买 |
| VNINE CITY（第九城堡） | 同上，提把处开线/损坏 | 少买 |

反向事实：25 款**可分解致癌芳香胺染料、甲醛全部合格**——面料安全没问题，坑在塑料小件和做工。

## 三、怎么用消协报告（比看名单更有用）

1. 报告里"符合标准"只代表**达到最低线**，不代表对得起价格——羽绒服那节就是典型（合格但只 86 克充绒）。
2. 看**项目**不看总分：书包看邻苯和缝合，羽绒服看绒子含量和绒丝+羽丝，寝具看可迁移元素和孔缝。
3. 原文在 cca.org.cn「比较试验」栏目、"消费查"平台可查；地方消协报告在当地消协官网。
4. 只在"样品负责"范围内下结论，别把一款样品的问题扩成整个品牌全品类。
