# 山东省监局通告速查：点名到牌子的那些

> 口径：只收**山东省市场监督管理局（省局）抽检通告、省级监督抽查结果、缺陷消费品召回**里点名到**品牌/企业/商品**的条目。
> 一句话：山东的食品抽检合格率很高（单期 98.7%），问题多是**糖、霉菌、维C虚标、农残**这类"单项踩线"；儿童用品端则集中在**童鞋塑化剂、童装绳带/纤维含量、书包邻苯**。

- 生产者端被点名：**青岛延赫服饰、青岛依霖与橦服饰、茌平东旭制衣厂**（3 家 4 批次）

## 三、召回（省局备案）

- **可比小鹿（青岛百丽制衣）** 中童休闲裤 120–160 码（2022.8–9 生产，10 件）→ **耐湿摩擦色牢度 + 绳带要求**不符合 GB 31701—2015（B 类），可能掉色、绳带被勾住摔倒。

## 四、怎么用

1. **蜂蜜看蔗糖**：洋槐蜜蔗糖超标是常见掺糖手法，买蜜认"波美度 + 蔗糖 ≤5 g/100g"。
2. **果干看霉菌**：山楂条、果脯类霉菌超限说明储运受潮，开袋有霉味直接退。
3. **功能饮料别信"补维C"**：这款标称补维 C 实测未检出，买功能饮料看营养成分表实测值，不看广告语。
4. **山东童鞋 16 批次不合格，四成是塑化剂**：给孩子买鞋先闻味、拉小附件、看鞋腔有无刺手。
5. **童装先剪绳带、先洗一遍**：山东这期 pH 值和色牢度是重灾区，新衣不洗直接穿等于让皮肤接触染料。
6. **书包认邻苯**：塑料件（印花、拉链头、背带扣）是邻苯重灾区，别买软胶味重的。
