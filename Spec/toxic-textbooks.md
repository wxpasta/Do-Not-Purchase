# 少买——毒教材 / 问题儿童读物

> 口径：教育部官方通报、出版社已道歉、或已被下架销毁的教材/儿童读物问题。
> 校内教材是统一发放的没法选，但**课外读物、绘本、历史普及书可以避开这些出版社和作者**。

| 品牌 / 产品 | 企业 / 涉事方 | 问题 | 处理结果 |
| ---- | ---- | ---- | ---- |
| 人教版小学数学教材（2012–2022 版） | **出版社**：人民教育出版社（社长黄强、总编辑郭戈）<br>**插图设计**：北京吴勇设计工作室（吴勇、封面设计吕旻、艺术指导吕敬人） | 插图人物丑陋、唐氏综合征面容、暴露/不适当动作、国旗错误、星条旗元素等 | 2022.08 教育部通报：27 人追责；黄强党内严重警告记大过；郭戈免职；不再聘请吴勇、吕旻、吕敬人及其工作室从事国家教材设计；教材全部重绘，2022.09 新学期启用新版 |
| 《写给孩子看的中国史·近代——救亡图存的斗争》（2017） | **出版社**：北京工业大学出版社 | 甲午战争章节配"丁汝昌投降图"——丁汝昌是自杀殉国的民族英雄，从未投降 | 2023.05：停售、全面收回销毁、出版社道歉；学校成立专班调查 |
| 《日本旅行，一本就够》（2023.03） | **出版社**：大连理工大学出版社 | 封面疑似使用靖国神社照片 | 网友曝光后引发争议 |
| 注音版"名家经典童话"（孙幼军作品） | **出版社**：北京少年儿童出版社（北京出版集团）<br>**作者**：孙幼军 | 标注"纯美暖心·国际安徒生奖提名"，正文含脏话内容 | 2023.03 网友曝光，出版社回应"每个人观感不同" |
| 《识字认读》（上册） | **出版社**：天津科学技术出版社（天津出版传媒集团） | 收录《小妹别生气》一文，内容"我吃香蕉你吃皮"等引发争议 | 2023.11 央视报道，出版社回应"观感不同" |
| 某儿童绘本（书名未公开） | **出版社**：江西美术出版社 | 含不适宜两性内容 | 2022 年已下架；2026.04 媒体跟进报道 |
