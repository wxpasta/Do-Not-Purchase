# 商场里办卡：什么情况下商场真的会赔

> 口径：商场内商户跑路、商场"不管"，是这两年的普遍现象，但不是"完全无法可依"。**能不能找商场，取决于四件事：商场有没有查执照、是不是"租赁柜台"、商户有没有失联、以及商场有没有统一收款。**
> **一句话结论**：**默认商场不赔；只有在"商场没查资质"或"柜台租赁+商场统一收款"两种情形下才可能赔。** 所以正确顺序是"先查执照→再办小额→跑路后找商户→找商场只作为补充"。

## 一、四个真实判决，把边界划清了

| 案子 | 情形 | 结果 |
| ---- | ---- | ---- |
| **天津高院典型案例（2026-03）** | 商场把场地租给**没有办学许可证**的少儿芭蕾培训机构，租赁合同里写了"要取得所有必要证照"，但商场**没有审查**；机构 2025-02 停课 | 判培训机构退未上课程费用，**商场依过错承担相应责任** |
| **最高法公报·车函倩案（连云港苏宁广场 / 亲亲袋鼠早教）** | 承租人倒闭后**主动联系消费者退费**，不存在经营者下落不明、租赁主体也不混乱 | **商场不承担赔偿责任**（消保法第 43 条不适用） |
| **牡丹区法院案例（2026-10）** | 美容店跑路，商场**尽到了资质审查义务** | **商场不承担退款**（合同相对性） |
| **鹤岗兴山区法院（2026-11）** | 游戏厅数度易主，消费者剩 **26000 枚游戏币（价值 19200 元）**，起诉经营方 + 场地出租方 | 调解后由经营方**退还现金**；法院明确"**游戏币不能兑现金**"不能当作拒退挡箭牌 |

## 二、什么时候可以找商场（四种情形）

1. **商场没查营业执照/经营资质**（最高法预付式消费司法解释**第六条**）——按过错承担民事责任，赔完可向商户追偿。
2. **"租赁柜台"模式 + 商场统一收款**（消保法**第四十三条**）——柜台租赁期满后可直接向出租者（商场）索赔；中消协律师 2026-05 明确这个路径。
3. **商户失联、找不到交易对象**——这是法院愿意往商场身上看的现实前提（车函倩案反向说明：商户主动退费、主体清晰，商场就不担责）。
4. **商场明知商户异常却不采取措施**——可依《民法典》**第一千一百九十八条**场所管理者安全保障义务主张**补充责任**；但中消协律师也提示：这类"知情证据"实践中很难拿到。

## 三、什么时候找商场没用

- 商场**尽到了形式审查**（看了执照、留了复印件）→ 不赔（牡丹区、天津案的对照面）。
- 商户**还在、还愿意退费或转店** → 商场不赔（车函倩案）。
- 你的钱**直接付给了商户**（扫码进商户账户、不是商场统一收银）→ 商场只是房东，不赔。
- 你只是"信任这个商场"才办卡 → 这不是法律理由，**合同相对方写的是谁，就找谁**。

## 四、为什么"商场不管"成了常态（结构原因）

- **轻资产化**：凯德把青岛凯德 MALL·新都心卖给基金、把长沙雨花亭卖给 REIT，产权方与运营方分离；万达 2023 年至今卖了 80 多座广场。**商场自己都在换业主**，更不会替商户兜底。
- **商户多是加盟/委管**：宝贝王 550 家里直营仅 15 家；金宝贝出事后总部第一句是"加盟商独立运营"。
- **监管制度有"末端留白"**：北京 2026-05 新办法要求预收余额达 20 万元须存管（普通不低于 20%、品牌发卡不低于 40%），但央广 2026-09 报道的汤泉品牌关店，两家门店**本应备案存管却查不到备案**——制度有，执行没有。
- **单笔金额小、维权成本高**：卡里剩几百上千，起诉不划算，正好被"拖"过去。

## 五、跑路后怎么打（按顺序，别乱）

1. **固定证据**：充值记录（微信/支付宝流水、刷卡单）、卡内余额截图、闭店现场照片、与店员/客服沟通记录、商场门店位置照片。
2. **找商户 + 找商场同时进行**：向商户发书面退款要求（微信文字也算），向商场客服**书面**登记（要工单号）。
3. **12315**（市场监管，投诉预付卡）＋ **商务主管部门**（举报单用途预付卡未备案/未存管）＋ **消协**（申请调解）。
4. **起诉**：只要能提供商户名称、住所地，**商户跑路也可缺席审理**；判后可执行。多人被同一家坑，走**代表人诉讼**或共同起诉降低成本。
5. **涉刑报案**：收预付款后停业、恶意逃避退款的，可主张**三倍惩罚性赔偿**（司法解释第二十三条），涉嫌诈骗的移送公安。
6. **别接受"转店"就签字**：转店方案通常免除商户退款义务；先算距离、剩余价值、承接方是否也在关店。

## 六、办卡前的三条硬检查

1. **查备案与存管**：问"在单用途预付卡平台备案了吗？钱进存管账户吗？"——北京、上海都有强制备案与存管办法，答不出就只买次卡。
2. **查执照与租期**：让商户出示营业执照（拍照留存），问租约到期日；**卡期超过租期就是风险敞口**。
3. **查收款方**：付款前看收款主体名称，和招牌不一致、或是个人账户，直接放弃。
