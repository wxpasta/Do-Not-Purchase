# 万象汇：哪些不能买

> 口径：万象汇是华润万象生活运营的区域型购物中心品牌（同系还有万象城、万象天地）。**商场本身未见撤场/违约记录，风险几乎全部集中在"场内第三方租户"**。
> **一句话结论**：万象汇里**儿童乐园的储值卡、早教的大课包、电玩的币**不要买；餐饮会员卡要先问"能不能退余额"；商铺"内铺返租"和"万象汇旁的住宅"不是一回事。

## 二、不能买清单

1. **场内儿童乐园/亲子中心的储值卡、年卡、次卡**——超级飞侠、NATAKIDS 都是"突然关门 + 商场说不负责"的组合；能单次买票就不要办卡。
2. **场内早教的"大课包"**（超过 3 个月/60 课时/5000 元）——金宝贝万象汇店就是闭店后只给"转校"，转过去的店自己也在陆续关。查"校外培训家长端"是否一课一消。
3. **电玩城、抓娃娃、海洋球池的游戏币**——这类余额不在单用途预付卡强制备案范围，跑路后没有任何保险理赔通道。
4. **"内铺"商铺（返租/统一经营）**——万象汇不少项目是**品牌输出 + 轻资产运营**（见下），产权方、运营方、商户三方分离，返租承诺不写进产权证。
5. **把"万象汇旁"当"华润开发"的住宅**——万象汇由华润万象生活运营，住宅由华润置地或其他开发商开发，是**两个主体**；看预售证上的开发企业，不看商场招牌。
6. **跨城通用的"会员储值"**——多数餐饮/乐园会员只在本地可用；转店方案往往"同城另一家店"，异地对你不成立。

## 三、万象汇的特殊结构（比万达更"干净"，也更难追责）

中山石岐万象汇是个可查的样本：**金鹰集团是场地所有者并出资改造，华润万象生活负责整体运营管理，万象汇只是品牌输出**；金阁佬还是业主自己的餐饮品牌、租自家物业。

含义有三条：
- **"万象汇"三个字不代表合同相对方**，收款方可能是某个加盟商、某个业主自营品牌，甚至某个二房东。
- 商场"不负责"有法律依据：最高法 2025-03 预付式消费司法解释**第六条**只规定了"场地出租者**未要求**租户提供经营资质证明、营业执照"的**过错责任**；商场尽到形式审查义务的，按合同相对性不承担退款（牡丹区法院案例）。
- 所以维权路径是**找商户 → 12315 → 起诉（可缺席审理）→ 涉刑报案**，而不是找商场闹。

## 四、反向事实（别把万象汇和万达混为一谈）

- **万象汇/万象城闭店基本给方案**：合肥 meland 提前发《告顾客书》+ 短信通知 + 点卡年卡可转两家店；中山金阁佬提前近一个月通知、可退余额。这与宝贝王"夜间撤场、小程序余额消失"是两个层级。
- **运营主体未见撤场记录**：本轮检索未见华润万象生活旗下商场整体停业、撤离的公开报道；风险是**租户层面的个体经营风险**，不是"商场要黄"。
- **改造型闭店是主因**：合肥 meland 闭店原因是商场 1–6 层改造，属于正常商业调整——**这类闭店反而更容易拿到退款/转店**。

## 五、三条验货

1. **看收款方**：扫码付款前确认收款主体名称，和招牌品牌不一致就只买次卡、不办年卡。
2. **看书面方案**：办卡时问一句"如果你们撤店，退余额还是转店？写进合同吗"——写不进合同的，默认按"转店"处理。
3. **控额度**：儿童乐园单次/次卡优先；早教不超 3 个月、60 课时、5000 元；电玩币一次别超两次游玩的量。
