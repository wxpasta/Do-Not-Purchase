# 哪些课不能买（校外培训 / 网课 / 知识付费）

> 口径：教育部与各地教育局"双减"合规提示、全国校外教育培训监管与服务综合平台规则、《中小学生校外培训服务合同（示范文本）》2021 修订版、市场监管行政处罚与刑事判例。
> **一句话结论**：**凡是"一次交超过 3 个月/60 课时/5000 元""转到个人账户或收现金""承诺保过、包就业、月入过万"的课，都不能买。** 三条里中任何一条，就不是"贵不贵"的问题，是**钱可能拿不回来**的问题。

## 一、政策红线（三条硬数字，直接当验货标准）

| 规则 | 内容 | 出处 |
| ---- | ---- | ---- |
| 收费上限 | **不得一次性收取或以充值、次卡变相收取超过 3 个月或 60 课时**的费用，且**总额不得超过 5000 元** | 各地教育局 2026 年合规提示（贵州/湖北/内蒙等） |
| 缴费渠道 | 必须通过「**全国校外教育培训监管与服务综合平台**」→「**校外培训家长端**」APP（或支付宝/微信小程序）选课缴费，费用进入**资金监管账户**，实行"**一课一消**" | 同上 |
| 机构资质 | 民办学校**办学许可证** + 营业执照（或民非证书），并公示在醒目位置；且在监管平台注册 | 同上 |

**三个"不"就是警报**：**个人账户收款 / 收现金 / 不在监管平台** → 教育局明确表述为"**逃避资金监管，家长资金存在极大风险隐患**"。

**共性套路（看到就退）**：①假人设（弃公职/救父病/创业逆袭/当过警察）②假案例（学员截图、进步榜、喜报）③假稀缺（限时名额、今天最后 X 个）④假保障（"全额退款""保过"）。这四样在监管处罚文书里被反复认定为**虚假宣传**。

## 三、不能买（清单）

1. **一次性卖 2 年卡 / 5 年卡 / 1000 节课包的**——超过 3 个月或 60 课时、5000 元即为违规销售。
2. **让你扫个人微信/支付宝、给现金、转对私账户的**——逃避资金监管，跑路时几乎不可能追回。
3. **"保过""包就业""保 offer""月入过万""学完接单"的**——全部是无依据承诺；教育培训广告本身**禁止对效果作保证性承诺**。
4. **"职业闭店人"接盘的机构**：特征——突然换老板/换销售/换前台、"正常人事变动"解释、老师陆续离职、承诺的 1 对 1 变成大课、户外活动取消。
5. **闭店前还在大促续费的**：FOX DANCE 就是停业前几天仍在群里发促销。**任何"最后一天优惠"的续费，都是风险最高的一笔钱。**
6. **不在"校外培训家长端"里的机构**（查不到 = 未纳入监管）。
7. **学科类培训在周末、节假日、寒暑假开班的**——"双减"下属于违规，随时被查停，课时费难退。
8. **"托管/自习室/研学/家庭教育咨询"包装的学科补习**——教育局已明确列为"隐形变异学科培训"。
9. **无办学许可证的"工作室""自习室"**（塔城案就是"智能自习室"发升学率广告）。
10. **学历提升"免考""包毕业"类**（石家庄案：冒充省考试院助学办）。

## 四、反向事实（怎么买才算稳）

- **优先"先学后付"**：多地教育局提示里明确写"优先选择先学后付模式"，这是目前最有效的风险对冲。
- **一课一消**：通过家长端 APP 缴费，钱在监管账户，按已上课时划扣；机构跑路，剩余课时资金仍在监管户里。
- **示范合同**：用教育部与市场监管总局《中小学生校外培训服务合同（示范文本）》（2021 年修订版），退费条款写清"按未消耗课时比例退"。
- **白名单**：先看当地教育局公示的**白名单机构**，再看价格。

## 五、三条验货（付款前 3 分钟做完）

1. **查平台**：打开"校外培训家长端"APP 搜这家机构——搜不到，不付钱。
2. **算数字**：这次要交的钱，**是否 ≤3 个月 且 ≤60 课时 且 ≤5000 元**；超一条就拆成两期，或换机构。
3. **验承诺**：把"保过/包就业/退款"写进合同的具体条款（含退款触发条件、时限、比例），**只肯口头承诺的一律视为没有**。
