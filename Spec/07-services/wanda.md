# 万达系：哪些不能买

> 口径：万达已经不是一个主体，而是四张皮——**万达商管（广场运营）／宝贝王（儿童乐园+早教）／万达电影（影城）／万达地产（楼盘）**。风险不在一个层级，买之前要先分清你面对的是哪张皮。
> **一句话结论**：**"万达广场里"的储值卡不要买，"万达"的期房要挑，"万达影城"的卡别跨城买，"宝贝王"的币别囤**。

## 一、四张皮，四种风险

| 板块 | 现状（可核查） |
| ---- | ---- |
| **万达商管（广场运营）** | 2023 年至今累计出售广场**超 80 座**，2025 年一次性打包转让 48 座，2026-02 上海颛桥万达广场 20.48 亿元出售；天眼查口径：大连万达商管 6 次未处理被执行记录、合计 **2.6 亿元**，大连万达集团 6 次、合计 **45.8 亿元**；惠誉 2026-11 披露：2026-06 底**现金约 46 亿元 vs 短期债务约 330 亿元**，评级维持 **CC**；2026 上半年新发美元债票息 **12.5%–12.75%** |
| **万达宝贝王** | 截至 2025-12 累计开业 550 家，**直营仅 15 家、委管 535 家**；2026-10-22 集团被列被执行人 50.06 万元；荆州店 2026-04-16 夜间撤场、东营店撤店不退费（万达答复"内租户纠纷不属万达管理范围"）。详见 [runaway-brands.md](runaway-brands.md) |
| **万达电影 / 万达影城** | 闭店按"租赁合同到期"处理，卡券转同城其他万达影城：哈尔滨南岗松雷 IMAX 店 2025-06-16 停业、卡券可转哈尔滨其他店；韶关百年东街店 2025-06-15 闭店，**退费只退本金、赠送金额不退**；郑州二七万达影城 2026-11-15 停业，购卡用户须在 11-15 前登记，卡券仅限河南省内其他万达影城使用 |
| **万达地产（楼盘）** | 武汉阳逻万达广场御江二期：合同约定 2022-12-30 交付，业主已收到**四次延期交付函**，2024 年发出联名"强制断供告知书"；沈阳万达盛京 ONE：合同 2024-09 交付，2025 年仍停在**三层**、2023 年即进"保交楼"，辽宁省住建厅多次约谈；兰州万达城 19 号地：合同 2025-05 交房，业主投诉 2025-12 起**长期停工**、工地锁门无人员设备 |

## 二、不能买清单

| 买什么 | 为什么不能买 / 要少买 |
| ---- | ---- |
| **万达广场里的第三方储值卡**（大玩家、神之领域、贝丁兔、各类儿童乐园/电玩） | 2026-11 天津武清万达广场 3 楼**大玩家、神之领域先后跑路**，贝丁兔同样涉储值卡问题，区里已多次联合商务局、市监、文旅、公安**约谈万达商管**；福州台江万达"大玩家"闭店后**余额默认转存到仓山万达店**，退款找不到人 |
| **宝贝王游戏币 / 成长卡 / 早教大课包** | 直营仅 15/550 家；荆州小程序余额停维后查不到；早教板块已有青岛 300 多孩子、内江 123 名孩子 60 余万、广州白云店等案例 |
| **万达影城的储值卡（尤其跨城买）** | 停业时只能转**同城**或**同省**其他万达影城；退费**只退本金、赠送金额不退**（韶关店口径）；异地卡等于打折券 |
| **万达广场的"内铺"商铺（返租/统一经营）** | 商场整体在卖资产、换股东，未来运营方变更直接影响返租与客流；产权与运营权分离，返租承诺不写进产权证 |
| **已延期交付的万达楼盘期房** | 御江二期 4 次延期函、盛京 ONE 保交楼 3 年、兰州万达城停工——这些是**已公开的延期/停工项目**，不是传闻 |
| **"万达广场旁""万达茂旁"的住宅** | 挂名不等于万达开发；要看预售证上的开发主体是不是万达地产系公司 |
| **万达商管的非上市股权/理财类产品** | 集团整体负债市场估算约 6000 亿元、惠誉评级 CC、票息 12%+ 融资——这类"高息"本身就是风险定价 |

## 三、关键法律口径（别指望"商场兜底"）

- 最高法 2025-03 发布《关于审理预付式消费民事纠纷案件适用法律若干问题的解释》**第六条**：商场场地出租者**未要求**租户提供经营资质证明、营业执照，致使无资质经营者收预付款造成损失的，消费者可请求商场**按过错承担民事责任**。
- 但现实判决是反向的：牡丹区法院案例中，商场**尽到了资质审查义务**，法院认定"合同相对性"，**商场不承担退款**（[案例](http://m.toutiao.com/group/7699080264202338835/)）。
- 结论：**只有商场"没查执照"这一种情形才可能赔**，"我在万达办的卡"本身不是索赔依据。第二十三条另有规定：经营者收预付款后停业、恶意逃避退款的，可主张**惩罚性赔偿**，涉刑的移送公安——这是找商家、不是找商场。

## 四、反向事实

- **万达影城闭店基本给方案**：哈尔滨、韶关、郑州都是提前公告 + 卡券转同城/同省门店，比宝贝王这类"夜间撤场"规范得多。
- **万达商管没违约公开债**：境内公开债 2025 年已全部清偿，2026-02 到期的 4 亿美元境外债展期至 2028 年（96% 债权人通过）。风险在**非公开市场与地产项目**，不在"广场明天关门"。
- **卖广场 ≠ 广场消失**：多数是股权易主、运营方仍可能是万达商管，但**新股东入局后运营策略会变**，这才是租户和储值卡的真实风险源。

## 五、三条验货

1. **分清主体**：卡/合同上的收款方是不是"万达"？大概率是某某商户或加盟公司——**认收款方，不认招牌**。
2. **看公告期**：影城、乐园撤场前一般有 15–30 天公告与登记期；**没见到书面公告就别充**。
3. **买期房查三样**：预售证上的开发主体、该项目是否进"保交楼"名单、预售资金监管账户是否公示。
