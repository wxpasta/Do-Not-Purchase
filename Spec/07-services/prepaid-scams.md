# 少买——预付服务跑路 & 保健品会销坑老

> 口径：两类预付费/高溢价消费陷阱。
> - **A 档（实锤）**：有监管处罚文书，或主流媒体调查核实、可追溯到法人主体。
> - **B 档（投诉线索）**：投诉平台集中反映关店不退费，**尚未见公开监管处罚结论**，列作风险预警，不作定性。
>
> 列定义：**品牌** = 消费者能直接看到的名字；**企业 / 涉事方** = 法人主体、分公司或门店公司。

## 怎么避

1. **预付款金额别高、周期别长**：北京规定营利性文化艺术类校外培训一次性缴费不超过 5000 元；理发、健身、瑜伽、托育同理，能按次付就别办大储值卡。
2. **先查主体再交钱**：合同盖章公司名和宣传品牌是否一致；上企查查/天眼查看有没有经营异常、限制高消费、合同纠纷、行政处罚记录。
3. **认准资金存管**：托育、教培的预付费应进入专用存管账户；要求出示存管凭证，不走私人转账、不进个人微信。
4. **警惕闭店前促销**：机构在跑路前往往搞店庆、低价大课包、老带新送礼——促销越猛越要小心。
5. **坑老套路识别**：免费鸡蛋/蔬菜引流 → 健康讲座/免费体验 → 专家背书、专利、抗癌治病话术 → 私域微信群一对一推销。普通食品/普通家电不能宣传治病功效，听到"降血糖、抗肿瘤、清血管"直接远离。
