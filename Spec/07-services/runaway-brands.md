# 有"跑路前科"的品牌：认牌子，别认招牌

> 口径：只收**全国性/跨城连锁品牌**，且至少有主流媒体调查、法院裁定、监管通报之一。地方小机构（卡莫瑜伽、爱乐乐享、乐融托育、中歌冒名等）见 [prepaid-scams.md](prepaid-scams.md)。
> **一句话结论**：跑路不是随机事件——**预付费 + 加盟 + 闭店前猛促销**这三个特征凑齐的品牌，历史记录里都跑过不止一次。

## 二、跑路前的共同信号（认这些比认牌子准）

1. **闭店前猛促销**：金宝贝南京、美吉姆南昌都是"关门前几天还在卖课"；乐融托育跑路前推 1288 元/48 节。**促销力度反常 = 现金流异常**。
2. **突然变更法人 / 被列经营异常 / 限高**：乐融关店前数次变更法人，校区公司已被限高。
3. **加盟商与总部切割**：金宝贝出事第一反应是"这 3 家是加盟商独立运营"——**加盟店跑路，总部不兜底**。
4. **"转课"代替退费**：舒适堡、一兆韦德、金宝贝全部先给转课方案，转课承接方往往次日反悔或限额。
5. **分期退款排到几十年**：金宝贝南京 25–30 年，本质是"不退"。
6. **让你办贷款/分期**：韦博、蛋壳都是"金融化"——**课没了、房没了，贷款还得还**。
7. **商场"内租户"身份**：宝贝王、大玩家、神之领域这类开在万达/商场里的店，一旦撤场，**商场第一反应是"租户与消费者的纠纷不归我们管"**（东营 2025-11 官方答复原文）。品牌挂着"万达"两个字，合同主体可能只是一家加盟/委管公司。

## 二·补：宝贝王这类"商场里的品牌"为什么要格外小心

- **直营只有 15 家、委管 535 家**（官方 2025-12 口径）——你在外地商场看到的宝贝王，绝大多数是**别人交加盟费挂的牌**，跑路与总部切割是标准动作。
- **收费统一进"集团账户"**：荆州官方答复称所有经营收费统一进入集团账户、退款只能走总部统一登记——意味着**地方门店没钱可退、地方监管也压不动总部**。
- **小额高频、维权成本高**：卡里往往只剩几百上千游戏币，单个消费者懒得起诉，正好被"拖"过去。
- **预付卡形态更脆弱**：游戏币、次卡、成长卡都不属于单用途预付卡强制备案范围，**没有保险理赔通道**（对比宜芝多还能按 32% 赔）。

## 三、已经跑了的，还能拿回多少

- **健身/教培/托育**：预付卡余额属**普通债权**，破产清偿顺位靠后（舒适堡明确提示"获赔前景不乐观"）。
- **单用途预付卡**：只有进了**保险/存管**的才可能按比例赔（宜芝多约 32%），没进存管的基本为零。
- **押金类（共享单车/公寓）**：债权仍有效、可主张，但公司"无财产可供执行"时等于纸面权利。
- **诉讼时效**：持续在 App 排队、向 12315 投诉可视为"主张权利"，能中断时效——**别一声不吭等**。

## 四、三条验货（办卡/交钱前 5 分钟）

1. **查主体**：合同盖章公司与招牌品牌是否一致；企查查/天眼查看"经营异常、限高、被执行人、合同纠纷"四项。
2. **查存管**：单用途预付卡有没有在**上海市单用途预付卡协同监管服务平台**（或本地对应平台）备案；教培是否走"校外培训家长端"一课一消。
3. **控额度**：一次性不超 3 个月/60 课时、不超 5000 元（教培红线）；健身、美容、托育同理——**能月付不年付，能次卡不储值**。
