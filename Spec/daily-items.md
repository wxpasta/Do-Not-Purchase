# 少买——日常小物件避坑

> 口径：每天用的小东西，但有质量问题/安全隐患/虚假宣传。

## 一、洗护产品（洗发水/沐浴露）

| 品牌 | 企业 / 涉事方 | 问题 | 事实 |
| ---- | ---- | ---- | ---- |
| 霸王 | 霸王（广州）化妆品有限公司 | 抽检不合格 | 2025.12：广州市化妆品专项抽检，霸王产品出现在不合格名单中（成分虚标/微生物污染） |
| 兔头妈妈 | 兔头妈妈（杭州）母婴用品有限公司 | 抽检不合格 | 2025.12：广州市化妆品专项抽检，兔头妈妈产品出现在不合格名单中 |
| 多款化妆品 | 多家企业 | 检出禁用原料 | 2024：国家药监局通告 10 批次化妆品检出禁用原料（甲基氯异噻唑啉酮等） |

**怎么避：**
- 看成分表：避开"甲基氯异噻唑啉酮"（MIT）——致敏防腐剂
- 别买太便宜的：洗发水沐浴露成本不高，但太便宜的肯定偷工减料
- 儿童用品更要注意：宝宝皮肤敏感，别买杂牌

## 二、卫生巾 / 纸尿裤

| 品牌 | 企业 / 涉事方 | 问题 | 事实 |
| ---- | ---- | ---- | ---- |
| 梁山希希纸制品 | 梁山希希纸制品有限公司 | 翻新卫生巾/纸尿裤 | 2025 315 曝光：以 260-1400 元/吨收购正规企业本该销毁的残次品，挑形状完整的重新包装卖 |
| 棉密码 | 棉密码（广州）生物科技有限公司 | 检出致癌物硫脲 | 2025.07：消费者送检发现多个批次硫脲含量超高（最高 16653 μg/g），达化妆品安全标准最低限量的 16 倍 |
| 好奇 / 碧芭宝贝 / Babycare | 金佰利 / 碧芭宝贝 / 杭州白菊实业 | 纸尿裤检出甲酰胺 | 2026.06：经济参考报委托检测机构抽样，多个品牌婴幼儿纸尿裤检出毒性物质甲酰胺 |
| 苏菲雅洁 | （低价杂牌） | 荧光增白剂 | 2025.03：媒体送检 11 款低价卫生巾，5.44 元的"苏菲雅洁"夜用款检出可迁移性荧光增白剂 |

**怎么避：**
- 别买太便宜的：5 块钱以下的卫生巾别碰
- 看品牌：护舒宝、ABC、苏菲等大品牌相对有保障
- 纸尿裤选大牌：好奇、花王、帮宝适等，别买杂牌
- 用的时候注意：有异味、起坨、漏的赶紧换

## 三、数据线 / 充电器

| 品牌 | 企业 / 涉事方 | 问题 | 事实 |
| ---- | ---- | ---- | ---- |
| 泡泡玛特盲盒数据线 | 泡泡玛特（POP MART） | 炸坏手机 | 2025.03：消费者买 39 元飞天小女警盲盒数据线，充电时 iPhone 15 Pro 主板+电池全烧坏 |
| 9.9 元廉价充电线 | （拼多多/淘宝杂牌） | 引发火灾 | 2025.05：河南用户网购 9.9 元充电线，充完电没拔，半夜起火；河北也有类似案例 |
| 多款电源适配器 | 多家企业 | 3C 认证不合格 | 2024：国家市监总局抽检，电源适配器 20 批次热塑性零部件不合格、18 批次抗电强度不合格 |

**怎么避：**
- 认准 3C 认证：没有 3C 标志的充电器别买
- 别买太便宜的：9.9 元的充电线 = 起火隐患
- 别买好看的杂牌：泡泡玛特这种 IP 联名数据线不是专门做充电的，质量没保障
- 用原装的：手机品牌原装数据线最贵但最安全
