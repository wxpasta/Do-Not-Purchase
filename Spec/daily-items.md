# 少买——日常小物件避坑

> 口径：每天用的小东西，但有质量问题/安全隐患/虚假宣传。

| 品牌 | 企业 / 涉事方 | 问题 | 事实 |
| ---- | ---- | ---- | ---- |
| 霸王 | 霸王（广州）化妆品有限公司 | 抽检不合格 | 2025.12：广州市化妆品专项抽检，霸王产品出现在不合格名单中（成分虚标/微生物污染） |
| 兔头妈妈 | 兔头妈妈（杭州）母婴用品有限公司 | 抽检不合格 | 2025.12：广州市化妆品专项抽检，兔头妈妈产品出现在不合格名单中 |
| 多款化妆品 | 多家企业 | 检出禁用原料 | 2024：国家药监局通告 10 批次化妆品检出禁用原料（甲基氯异噻唑啉酮等） |

**怎么避：**
- 看成分表：避开"甲基氯异噻唑啉酮"（MIT）——致敏防腐剂
- 别买太便宜的：洗发水沐浴露成本不高，但太便宜的肯定偷工减料
- 儿童用品更要注意：宝宝皮肤敏感，别买杂牌

| 多款电源适配器 | 多家企业 | 3C 认证不合格 | 2024：国家市监总局抽检，电源适配器 20 批次热塑性零部件不合格、18 批次抗电强度不合格 |

- 用原装的：手机品牌原装数据线最贵但最安全

## 五、厨房用品（锅具 / 餐具）

| 品牌 | 企业 / 涉事方 | 问题 | 事实 |
| ---- | ---- | ---- | ---- |
| 康巴赫 | 浙江康巴赫厨具有限公司 | 不粘锅涂层脱落 + 虚假宣传 | 2022：消费者投诉新买锅使用仅半个月涂层大面积脱落、严重粘锅；官方旗舰店宣传与实际质量不符 |
| 多款"0 涂层"锅 | 多家品牌 | "0 涂层"宣称不实 | 2025.04：上海市消保委测评 20 款平底不粘锅，部分宣称"无化学涂层/0 涂层"的样品仍刮取出涂层粉末 |
| IKEA 宜家 | 宜家（中国）投资有限公司 | 炒锅涂层标识缺失 | 2023：召回广州天河门店售出的 2543 件炒锅；涂层含聚四氟乙烯，未标识"使用温度不得高于 250°C"，空烧/油沸腾会破坏涂层、污染食品 |
| 双立人 / 张小泉 / 菲仕乐 / WMF / 巴拉利尼 | 各品牌中国分公司 | 锅具标签标识不完整 | 2025.03：京津冀消协联合测试，上述品牌均未标注限制性物质名单及总迁移量合规情况 |
| 密胺塑料餐具 | 多家生产/销售企业 | 安全项目不合格 | 2026.08：河南省市监局抽查 40 批次密胺塑料餐具，1 批次安全项目不合格（密胺=仿瓷塑料，高温盛热油可能析出三聚氰胺） |

**怎么避：**
- 不粘锅别空烧：特氟龙涂层超过 250°C 会分解，热油冒烟、干锅空烧都危险
- "0 涂层"多是营销话术：真正不粘的锅基本都有涂层，别为这个噱头多花钱
- 涂层一脱落就换：掉涂层的锅继续用，吃进去的都是塑料
- 密胺（仿瓷）碗别装滚烫的汤/油：高温析出三聚氰胺，给小孩盛饭用瓷碗
- 木筷子半年一换：发霉、起毛刺就扔，别用到黑
