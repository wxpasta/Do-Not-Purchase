# 少买——国际已禁用 / 中国仍合法使用的食品添加剂

> 口径：不是"非法添加"，而是**中国 GB 2760 仍允许、但欧美日等主要经济体已禁用或严格限制**的添加剂。
> 买食品时翻配料表看到这些词，可以心里有数、尽量避开。
>
> 第一列是**添加剂名称**（不是品牌），因为本清单针对的是物质本身。

## 一、中国仍在合法使用

| 添加剂 | 功能 | 国际禁用/限制情况 | 中国现状 | 常见出现位置 |
| ---- | ---- | ---- | ---- | ---- |
| 甜蜜素（环己基氨基磺酸钠） | 甜味剂 | 美国 1969 年起禁用；日本禁用 | GB 2760 允许用于饮料、果冻、果酱、面包、糕点、配制酒等，最大 0.65–1 g/kg | 无糖饮料、蜜饯、果冻、糕点 |
| 脱氢乙酸钠（脱氢乙酸及其钠盐） | 防腐剂 | 欧盟不允许作为食品添加剂（仅化妆品可用）；美国仅允许切块/去皮南瓜和草莓（≤65 mg/kg）；日本仅允许黄油、奶酪、人造黄油（≤0.5 g/kg） | GB 2760-2024 已从面包、糕点、淀粉制品等 7 类删除；腌渍蔬菜最大量从 1 g/kg 降至 0.3 g/kg，但腌渍蔬菜/食用菌仍合法使用 | 酱菜、泡菜、腌渍蔬菜、熟肉制品 |
| 胭脂红（Ponceau 4R） | 合成色素 | 美国不许可用于食品；挪威等国禁用 | GB 2760 允许用于饮料、糖果、糕点、果酱等 | 草莓味饮料、糖果、糕点装饰 |
| 柠檬黄（Tartrazine） | 合成色素 | 挪威、澳大利亚不允许用于食品加工 | GB 2760 广泛允许用于饮料、糖果、糕点等 | 柠檬味饮料、糖果、方便面调料包 |
| 日落黄（Sunset Yellow） | 合成色素 | 挪威、芬兰不允许用于食品 | GB 2760 广泛允许 | 橙味饮料、糖果、熟食 |
| 亮蓝（Brilliant Blue） | 合成色素 | 澳大利亚、比利时、丹麦、法国、希腊、意大利、西班牙、瑞士、挪威等多国禁用 | GB 2760 广泛允许 | 蓝柑饮料、糖果、冰淇淋 |

## 二、中国刚禁用 / 已禁用（历史对照）

| 添加剂 | 功能 | 国际禁用情况 | 中国禁用时间 | 备注 |
| ---- | ---- | ---- | ---- | ---- |
| 偶氮甲酰胺（ADA） | 面粉处理剂 / 增筋剂 | 欧盟、澳大利亚、新西兰、日本、新加坡均禁用 | GB 2760-2024 删除，2025.02.08 生效 | 分解物联脲（ semicarbazide ）被怀疑致癌；曾广泛用于小麦粉 |
| 过氧化苯甲酰 | 面粉增白剂 | 欧盟不允许使用任何面粉漂白剂 | 2011.05.01 起禁止在面粉中使用 | 中国曾允许 0.06 g/kg；美国、加拿大、日本曾允许 |
| 溴酸钾 | 面粉处理剂 | 欧盟、英国等禁用 | 2005.07.01 起禁止在面粉中使用 | 被认为有致癌性 |


## 三、中国法律明确禁止的非法添加物

> 以下不是"食品添加剂"，是卫生部（现国家卫健委）公布的**非食用物质黑名单**——在食品中添加即违法，被查到就是刑事案件。
> 来源：卫生部《食品中可能违法添加的非食用物质名单》（第1–5批汇总，共47种），选消费者最常碰到的10种。

| 非法添加物 | 常被加在什么里 | 危害 |
| ---- | ---- | ---- |
| 三聚氰胺（蛋白精） | 乳及乳制品 | 肾结石、肾衰竭（2008 三鹿奶粉事件） |
| 苏丹红 | 辣椒粉、辣椒酱、辣味调味品 | 致癌（2005 肯德基/麦当劳苏丹红事件） |
| 吊白块（甲醛次硫酸氢钠） | 腐竹、粉丝、面粉、竹笋 | 分解产生甲醛，致癌 |
| 硼酸 / 硼砂 | 腐竹、肉丸、凉粉、面条、饺子皮 | 蓄积中毒，损害消化道、肝肾 |
| 工业甲醛 | 海参、鱿鱼等干水产品、血豆腐 | 致癌、刺激黏膜 |
| 工业硫磺 | 银耳、生姜、蜜饯、辣椒、白砂糖 | 二氧化硫残留，刺激呼吸道 |
| 罂粟壳 | 火锅底料、小吃 | 成瘾性，毒品原植物 |
| 孔雀石绿 | 鱼类（水产运输） | 高毒、致癌、致畸 |
| 瘦肉精（盐酸克伦特罗） | 猪肉、牛羊肉 | 心悸、手抖、心律失常 |
| 地沟油（废弃食用油脂） | 食用油脂 | 黄曲霉素、苯并芘等致癌物 |
## 四、买前自查小技巧

1. **翻配料表**：看到"环己基氨基磺酸钠/甜蜜素"、"脱氢乙酸钠"、"胭脂红/柠檬黄/日落黄/亮蓝"，优先选无添加版本。
2. **看颜色**：特别鲜艳的饮料、糖果、糕点，大概率用了合成色素。
3. **看保质期**：保质期极长的酱菜、熟食，留意是否含脱氢乙酸钠。
4. **无糖饮料**：注意区分"赤藓糖醇/甜菊糖"（天然代糖）和"甜蜜素/阿斯巴甜"（人工合成）。
