# 少买——食品添加剂对照（儿童选购向）

> **先分清三类口径，别把合法添加剂当毒物：**
> 1. **非法添加物（一律不能吃）**：不是食品添加剂，是国家卫健委公布的非食用物质黑名单，检出即违法，严重的追刑事责任。
> 2. **国标已禁用 / 撤销**：现行标准不允许再用于对应食品，买到属于违规。
> 3. **国标允许、但建议给孩子尽量回避**：在限量内使用对健康成人是安全的，但儿童处于发育期，配料表能不选就不选；这类不等于"吃了就中毒"。
>
> 第一列是**添加剂名称 / 配料表别名**（不是品牌），清单针对物质本身。

## 一、中国仍在合法使用（儿童尽量回避）

### 1. 人工合成甜味剂

> 多出现在"无糖 / 低糖"饮料、糖果、果冻、糕点、蜜饯里。人工合成代糖不提供营养，儿童不建议常喝含这类甜味剂的饮料；天然代糖（赤藓糖醇、甜菊糖苷、罗汉果苷）相对更可选。

| 配料表名称 / 别名 | 功能 | 国际态度 / 风险 | 常见儿童食品 | 口径 |
| ---- | ---- | ---- | ---- | ---- |
| 甜蜜素（环己基氨基磺酸钠） | 甜味剂 | 美国 1969 年起禁用；日本禁用；GB 2760 允许用于饮料、果冻、果酱、面包、糕点、配制酒等 | 无糖饮料、蜜饯、果冻、糕点 | 合法，儿童尽量回避 |
| 安赛蜜（乙酰磺胺酸钾） | 甜味剂 | GB 2760 允许：饮料类 0.3 g/kg（包装饮用水、果蔬汁除外）、糖果 2.0 g/kg 等；常与阿斯巴甜复配 | 无糖饮料、口香糖、糖果、糕点 | 合法，儿童尽量回避 |
| 三氯蔗糖（蔗糖素） | 甜味剂 | GB 2760 允许用于饮料、糖果、糕点、乳制品等；甜度高、不留热量 | 无糖饮料、酸奶、糖果、饼干 | 合法，儿童尽量回避 |
| 阿斯巴甜（天门冬酰苯丙氨酸甲酯） | 甜味剂 | GB 2760 允许；IARC 列为 2B 类"可能对人类致癌"（证据有限）；**苯丙酮尿症患者不能食用**，包装须标注 | 无糖饮料、口香糖、糖果、酸奶 | 合法，儿童尽量回避；PKU 人群禁用 |
| 糖精钠 | 甜味剂 | 老一代人工甜味剂，多国限制使用范围；GB 2760 仅限部分食品 | 蜜饯、话梅、瓜子等 | 合法，儿童尽量回避 |

**对照：相对可选的代糖**——赤藓糖醇、甜菊糖苷（甜菊糖）、罗汉果苷；配料表出现这些，比上述人工合成代糖更适合儿童（仍属甜味，需控量）。

### 2. 合成色素

> 颜色异常鲜艳的饮料、糖果、糕点、冰淇淋大概率使用合成色素；《儿童零食通用要求》团体标准不允许儿童零食使用人工色素。

| ---- | ---- | ---- | ---- | ---- |
| 胭脂红（Ponceau 4R） | 红 | 美国不许可用于食品；挪威等国禁用 | 草莓味饮料、糖果、糕点装饰 | 合法，儿童尽量回避 |
| 柠檬黄（Tartrazine） | 黄 | 挪威、澳大利亚不允许用于食品加工 | 柠檬味饮料、糖果、方便面调料包 | 合法，儿童尽量回避 |
| 日落黄（Sunset Yellow） | 橙/黄 | 挪威、芬兰不允许用于食品；本清单有泰式奶茶日落黄超标实锤 | 橙味饮料、糖果、熟食、奶茶 | 合法，儿童尽量回避 |
| 亮蓝（Brilliant Blue） | 蓝 | 澳大利亚、比利时、丹麦、法国、希腊、意大利、西班牙、瑞士、挪威等多国禁用 | 蓝柑饮料、糖果、冰淇淋 | 合法，儿童尽量回避 |
| 诱惑红（Allura Red AC） | 红 | 多国限制；部分研究提示与儿童多动行为相关，证据尚不充分 | 草莓/樱桃味饮料、糖果、冰淇淋、肉制品 | 合法，儿童尽量回避 |

### 3. 含铝膨松剂（明矾）

| 配料表名称 / 别名 | 功能 | 规定与风险 | 常见出现位置 | 口径 |
| ---- | ---- | ---- | ---- | ---- |
| 硫酸铝钾（钾明矾、明矾）、硫酸铝铵（铵明矾） | 膨松剂 / 面粉处理剂 | 2014 年原卫计委等 5 部门第 8 号公告：**膨化食品不得使用含铝食品添加剂**；小麦粉及其制品（油炸面制品、面糊、裹粉、煎炸粉除外）不得使用硫酸铝钾 / 铵；食品铝残留 ≤100 mg/kg。铝是非必需元素，过量摄入损害中枢神经，可影响儿童神经发育；7–14 岁儿童铝摄入主要来自膨化食品 | 油条、油饼、麻花、粉条、馒头（违规添加时）；膨化食品按规定不应含 | 限定范围合法；膨化食品、馒头发糕中出现属违规，儿童回避 |

### 4. 防腐剂 / 保鲜剂

| 配料表名称 / 别名 | 功能 | 风险与现状 | 常见出现位置 | 口径 |
| ---- | ---- | ---- | ---- | ---- |
| 脱氢乙酸钠（脱氢乙酸及其钠盐） | 防腐剂 | 欧盟不允许作为食品添加剂（仅化妆品可用）；美国仅允许切块/去皮南瓜和草莓（≤65 mg/kg）；日本仅允许黄油、奶酪、人造黄油（≤0.5 g/kg）。GB 2760-2024 已从面包、糕点、淀粉制品等 7 类删除；腌渍蔬菜最大量由 1 g/kg 降至 0.3 g/kg，腌渍蔬菜/食用菌仍合法 | 酱菜、泡菜、腌渍蔬菜、熟肉制品；面包糕点中出现属违规 | 合法范围收窄，儿童尽量回避 |

| 亚硝酸钠 / 硝酸钠（护色剂） | 护色、抑菌 | 肉制品专用，可生成亚硝胺；儿童不宜常吃腌制肉、香肠火腿 | 火腿肠、肉松、腌腊肉制品 | 合法限量，儿童少吃加工肉制品 |

## 三、中国法律明确禁止的非法添加物

> 以下不是"食品添加剂"，是卫生部（现国家卫健委）公布的**非食用物质黑名单**——在食品中添加即违法，被查到就是刑事案件。
> 来源：卫生部《食品中可能违法添加的非食用物质名单》（第1–5批汇总，共47种），选消费者最常碰到的10种。

| 非法添加物 | 常被加在什么里 | 危害 |
| ---- | ---- | ---- |
| 三聚氰胺（蛋白精） | 乳及乳制品 | 肾结石、肾衰竭（2008 三鹿奶粉事件） |
| 苏丹红 | 辣椒粉、辣椒酱、辣味调味品 | 致癌（2005 肯德基/麦当劳苏丹红事件） |
| 吊白块（甲醛次硫酸氢钠） | 腐竹、粉丝、面粉、竹笋 | 分解产生甲醛，致癌 |
| 硼酸 / 硼砂 | 腐竹、肉丸、凉粉、面条、饺子皮 | 蓄积中毒，损害消化道、肝肾 |
| 工业甲醛 | 海参、鱿鱼等干水产品、血豆腐 | 致癌、刺激黏膜 |
| 工业硫磺 | 银耳、生姜、蜜饯、辣椒、白砂糖 | 二氧化硫残留，刺激呼吸道 |
| 罂粟壳 | 火锅底料、小吃 | 成瘾性，毒品原植物 |
| 孔雀石绿 | 鱼类（水产运输） | 高毒、致癌、致畸 |
| 瘦肉精（盐酸克伦特罗） | 猪肉、牛羊肉 | 心悸、手抖、心律失常 |
| 地沟油（废弃食用油脂） | 食用油脂 | 黄曲霉素、苯并芘等致癌物 |
## 四、买前自查小技巧

1. **翻配料表，按类别对号入座：**
   - 甜味剂：甜蜜素、安赛蜜（乙酰磺胺酸钾）、三氯蔗糖（蔗糖素）、阿斯巴甜、糖精钠；优先选赤藓糖醇、甜菊糖苷、罗汉果苷。
   - 色素：胭脂红、柠檬黄、日落黄、亮蓝、诱惑红；颜色越鲜艳越要警惕。
   - 膨松剂：硫酸铝钾、硫酸铝铵（明矾）；膨化食品按规定不应含铝。
   - 防腐剂：脱氢乙酸钠、苯甲酸钠、山梨酸钾、二氧化硫/焦亚硫酸钠；面包糕点里出现脱氢乙酸钠属违规。
2. **看颜色**：特别鲜艳的饮料、糖果、糕点，大概率用了合成色素。
3. **看保质期**：保质期极长的酱菜、熟食，留意是否含脱氢乙酸钠、苯甲酸钠。
4. **无糖饮料**：区分"赤藓糖醇/甜菊糖"（天然代糖）和"甜蜜素/阿斯巴甜/安赛蜜/三氯蔗糖"（人工合成）。
5. **给孩子选零食**：配料表越短越好；前几位是糖、植物油、香精、色素、甜味剂的，不当日常零食。
