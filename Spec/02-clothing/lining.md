# 李宁（LI-NING）：哪些商品踩过雷

> 口径：只收**省市监局抽检通告、工商抽检、权威媒体送检**的条目；无处罚结论的标 B 档。
> 一句话结论：李宁的问题不在"整体不行"，而在**羽绒类的充绒量/绒子含量**、**服装色牢度**、**儿童线（童装、儿童泳衣）的标识与色牢度**这三处反复出现。

## 一、被抽检判定不合格（官方通告）

| 商品 | 标称生产企业 | 不合格项 / 出处 |
| ---- | ---- | ---- |
| 短羽绒服（1 批次） | 李宁（中国）体育用品有限公司 | 2022 年无锡市市监局羽绒服装抽检：**羽绒含绒量、绒子含量**项目不合格（2023.02 经《中国消费者报》报道） |
| 羽毛球系列比赛上衣（170/92A L） | 李宁（中国）体育用品有限公司 | 河北省市监局 2024.05.22 产品质量抽检通告：**耐光色牢度**不合格（同批 6 批次服装不合格，涉探拓、Urlazh 有兰、世奥得等） |
| 户外服装（1 组） | 标称商标 LI-NING | 吉林省工商局流通领域户外服装、鞋类抽查：50 组样品 **24 组不合格**，不合格项涉速干性、吸湿性、防紫外线性能、纤维成分及含量、色牢度；LI-NING 在名单内 |
| 儿童服装（1 批次） | 李宁体育童装有限公司 | 海南省市监局《2023 年流通市场儿童服装产品质量监督抽查》：抽查 60 批次、**不合格 10 批次（16.7%）**，不合格项含绳带要求、pH 值、使用说明（标识）、耐湿摩擦色牢度；名单中出现"李宁体育童装有限公司" |

## 二、媒体送检（儿童泳衣，2018）

- 某地消委会/媒体送检 11 个批次儿童泳装，**9 个批次不符合标准（81.8%）**，涉产品使用说明、纤维含量、耐光色牢度、拉伸弹性伸长率。
- **李宁牌游泳衣**：产品使用说明、**拉伸强度**两项不符合标准；同批迪士尼、迪卡侬的拉伸强度也不合格。
- 提示：儿童泳衣属高弹面料，拉伸强度不达标会"越穿越松、兜不住水"，安全性下降。

## 三、渠道风险（假冒李宁）

- 广西平南：某店销售侵犯"LI-NING"商标专用权 T 恤 20 件，被没收并罚 3500 元（平市监处罚〔2024〕484 号）。
- 结论：**李宁是被假冒最多的国产运动品牌之一**，县城集合店、"外贸原单"、"剪标尾货"是重灾区；只认官方旗舰店、直营店、授权经销（可在官网查授权门店）。

## 四、结论：李宁什么别买

1. **羽绒服/羽绒马甲**：含绒量、绒子含量被查出过不合格，买时看洗唛标注的"绒子含量 %"和充绒克数，别只看"90 绒"大字。
2. **深色、荧光色比赛服/训练服**：耐光色牢度不合格意味着晒几次就褪色、变旧；户外穿的建议选浅色或深色基础款。
3. **儿童线（童装、儿童泳衣）**：绳带、pH、标识、色牢度都出现过问题——给孩子买先剪掉可抽出的绳带、新衣先洗、泳衣看拉伸回弹。
4. **县城集合店与"剪标尾货"**：假冒案多发，价格明显低于官方渠道的一律不买。
