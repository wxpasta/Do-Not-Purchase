# 耐克（Nike）：哪些产品踩过雷

> 口径：只收**官方处罚、海关总署/省市监局通报、央视 3·15 曝光**的条目；假货案件属渠道问题，单列说明。
> 先给结论：耐克在中国的问题集中在两处——**"宣传的配置"与"实际配置"不一致**（气垫门，两次，其中一次被罚 487 万），以及**儿童服装/童鞋的色牢度、化学安全项**（海关与省级抽检通报）。

## 一、宣传与实际不符（有官方处罚，重点）

| 事件 | 产品 | 事实 / 处罚 |
| ---- | ---- | ---- |
| 2011 年"减配气垫" | Hyperdunk 2011 篮球鞋 | 中国版前脚掌比美国同款**缺少气垫**；耐克称"宣传失误"，只做全额退款。**北京市工商局认定侵害中国消费者权益，开罚 487 万元** |
| 2017 年"气垫门"（3·15 曝光） | Hyperdunk 2008 FTB 男子篮球鞋（复刻版，1499 元/双） | 中文官网宣称后跟带专利 **zoom air 气垫**，消费者切开鞋跟**并无气垫**；该款售出 300 多双。耐克先称"宣传资料使用错误"，宣称的召回并未在工商备案（上海徐汇区市监局答复"从未接到备案"）。上海市杨浦区市监局立案调查，最终**退货 + 全额退款 + 4500 元（约三倍赔偿）**，90 天内办理 |

> 判断口径：耐克这两次都不是"质量不合格"，而是**"说的和做的不一样"**。买限量复刻、联名款时，宣传页上的科技配置要留截图；拿到手发现不符，属虚假宣传，可主张退一赔三。

## 二、儿童产品被通报不合格

| 通报 | 产品 | 不合格项 |
| ---- | ---- | ---- |
| 海关总署 2021.06.01 进口儿童用品质量通报（2020.06–2021.05 查发 81 批次） | 耐克部分**儿童服装** | **耐湿摩擦色牢度不合格**；同批还有无印良品、GAP、H&M、ZARA 等 10 个品牌。官方提示：染料或有害物质可能通过皮肤、口腔被人体吸收，危害健康 |
| 海南省市监局 2021 年流通市场儿童鞋抽查 | 耐克商业（中国）有限公司三亚凤凰路分公司 在售儿童鞋（款号 BQ0102-024） | 被列入**不合格批次名单**；该次抽查安全项不合格集中在**重金属总量、邻苯二甲酸酯**，使用性不合格为标识、耐磨性能 |

> 儿童鞋的化学风险口径：邻苯二甲酸酯可能干扰内分泌、与儿童性早熟相关；重金属总量超标会在体内蓄积。给孩子买鞋，认 **GB 30585（儿童鞋安全技术规范）**与 3C，不认成人运动品牌的"降龄款"。

## 三、假货与渠道（不是耐克本身的问题，但最容易被坑）

2025 年多地市监处罚显示，**假冒耐克**在县城集合店、流动摊点、上门推销渠道仍普遍：

- 河北保定清苑：潮品集合服装店从广州流动摊点进 25 双"NIKE"运动鞋（进价 110、售价 160），售出 18 双，经商权利害关系人鉴定为**假冒**，没收 7 双、罚款 6000 元（清市监处罚〔2025〕90013 号）
- 海南海口：多起拖鞋、袜子、步鞋、行礼包假冒案，罚款 300–1000 元
- 安徽固镇：假冒耐克棉服 1 件，罚 500 元

**给孩子买耐克的四条**：

1. **只在官方渠道买**：Nike 官网/App、官方旗舰店、直营店；县城集合店、直播间"尾货"、上门推销是假货高发区。
2. **限量复刻款先截图**：宣传页的科技配置（气垫、碳板）截图留存，收货先验，不符可主张退一赔三。
3. **儿童服装看色牢度**：深色印花童装先用水搓一下，掉色明显就别给孩子贴身穿；认 GB 31701 A 类标识。
4. **儿童鞋认 GB 30585**：闻气味（刺鼻胶味多与胶粘剂有关）、看标识齐全，别买无厂名厂址的"外贸原单"。
