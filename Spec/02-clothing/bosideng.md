# 波司登（Bosideng）：哪些商品别买

> 口径：只收**省市抽检、中消协比较试验、权威媒体报道**的条目。
> 先说清楚：**波司登本品牌近年在国家/省市抽检中没有被点名不合格**；被点过的是旗下子品牌**冰洁**（清洁度），而现在争议最大的是**"高价低充绒量"**（B 档，多次上热搜，属定价与宣传问题，不是质量不合格）。

## 一、有抽检不合格记录（子品牌）

| 商品 | 品牌 / 主体 | 问题 / 出处 |
| ---- | ---- | ---- |
| 羽绒服（多批次） | **冰洁**（波司登旗下） | 2012 年安徽合肥、芜湖、铜陵、滁州、宣城 5 市工商/消协抽检 37 组羽绒服，**不合格率 19%**，不合格项为**清洁度**（羽绒中混有有害物质，长期穿着危害健康）；7 个不合格样本涉冰洁、千仞岗、欧尚等 |

## 二、参加过比较试验但未被点名（避免误伤）

- 中消协 2026.02 公布 **30 款儿童羽绒服比较试验**：安全性检测中，**所有样品的纤维含量、甲醛、pH 值均表现良好**。
- 品质检测中未达标的 3 款是**贝肽斯、PUMA、雅鹿**（绒子含量、绒丝+羽丝不达标）。
- 波司登是参评的 30 个品牌之一，**未被点名品质不合格**；个别样品存在问题的是"产品使用说明不规范"这一类（属标注问题）。

## 三、B 档：高价低充绒量（当下最该盯的点）

| 时间 | 商品 | 事实 |
| ---- | ---- | ---- |
| 2024 | 售价 700 多元的羽绒裤 | 被指**充绒量仅 3 克**（几乎等于没有填充） |
| 2026.01 | 男士商务系列鹅绒羽绒服，原价 2299 元、折后 1947–1999 元 | 网友晒水洗标：175 码**充绒量 86 克**（165/170/175 分别为 78/82/86 克），绒子含量 90%、蓬松度 700FP。官方客服回应"**充绒量符合国家标准**，价格取决于综合性因素"；该款已售 2000 多单，话题登热搜 |
| — | 品牌宣传 | 波司登曾登记"羽绒服权威专家""中国防寒服专家""羽绒服（防寒服）**第一品牌**"等广告语著作权，属营销话术 |

> 关键口径：**"符合国家标准"≠"对得起价格"**。国标 GB/T 14272—2021 只规定标注与最低要求，不规定"多少钱必须充多少绒"。86 克对短款轻薄款是正常区间，但对标价 2000+ 的"加厚商务款"就属偏薄——这就是争议核心。

## 四、结论：波司登什么别买

1. **不看充绒量的"高端商务款"**：先看水洗标，175 码 86 克基本是轻薄档，冬天单穿不够；同价位可横向比比充绒克数。
2. **羽绒裤**：出现过"充绒 3 克"的先例，买前一定翻水洗标看充绒量，别只看厚度手感。
3. **为"第一品牌""权威专家"话术付费**：这类是广告语，不是质量指标。
4. **子品牌冰洁老批次**：历史上清洁度不合格，买老款/折扣仓存货注意生产年份。
5. **儿童羽绒服**：认三样——**绒子含量 %、充绒量 g、GB 31701 A 类**；中消协的选购口诀是"一看标识、二选产品、三闻气味、四维护"（拍打看有无粉尘、闻有无腥臭霉味）。
