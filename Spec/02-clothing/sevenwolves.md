# 七匹狼（SEPTWOLVES，福建七匹狼实业 002029）：哪些不能买

> 口径：央视《每周质量报告》＋江苏省市场监管局抽检、原国家质检总局电商专项抽查、北京/天津/广州工商抽检、市场监管处罚案例、公司年报。
> **先给结论**：七匹狼的问题不在"厂"，在**品类授权与电商款**。**围巾/配饰**是重灾区——2021 年央视从**七匹狼天猫旗舰店**买的围巾，吊牌 96% 羊毛实测 0 羊毛；**内衣、内裤、袜子**这条针纺线历史上多次出**pH 超标**（生产方是浙江开倜等授权/代工企业）；吊牌爱用"**波斯纶**"这类非法定纤维名称。买主标夹克、外套、休闲裤相对稳（这些部分自制）。

## 一、最硬的一条：2021 年央视点名，且出在"旗舰店"

**2021-03-28 央视《每周质量报告》＋江苏省市场监管局围巾抽检**

| 事实 | 细节 |
| ---- | ---- |
| 样品来源 | **电商平台"七匹狼旗舰店"购买** |
| 第 1 条围巾 | 吊牌标 **96% 羊毛**，实测 **100% 聚酯纤维（涤纶）——一根羊毛都没有** |
| 第 2 条围巾 | 标羊毛、羊绒各 50%，实测**无羊绒**，"羊绒"实为聚酯纤维 |
| 不合格名单 | 10 批次，含"标称为**七匹狼牌**"（其余为雷郭堡、百瑞欧、SHOWMEISHI、The Green Party、玮希佳品、金鹤、MOSHOU、迪昆希、手帽金） |
| **更关键的一处** | 该旗舰店产品详情页**向消费者出示了一份"检测合格报告"**；苏州市纤维检验院核查后指出：这份报告**只测了耐水、耐汗渍、耐干摩擦色牢度，未测甲醛、pH、可分解芳香胺、纤维含量**——**报告不齐全，缺项目** |

**这条的用法**：不是"七匹狼全线造假"，而是——**旗舰店详情页贴的检测报告可能只覆盖它测得过的项目**。以后看到"权威检测合格"截图，看它测了哪几项，尤其**有没有纤维含量**。

**公司自己的回应（2021-03-31 晋江经济报）**：涉事围巾吊牌为"6% 美利奴羊毛、20% 腈纶、20% 锦纶、**54% 波斯纶**"，实测"绵羊毛 3.8%、聚酯纤维 40.1%、腈纶 36.2%、锦纶 19.9%"；称羊毛、锦纶"均符合国家检测要求，差异在法定允差范围内"，不合格原因是"**吊牌标识的波斯纶为复合纤维，不符合国家规范中对于纤维表述的约定**"。同时澄清"96% 羊毛不含一根羊毛"等 9 批次与其无关。
→ 客观结论：**羊毛实测 3.8% vs 标 6%，确在允差内**；但这恰恰暴露这家的问题方式是**用非法定纤维名称（"波斯纶"）写吊牌**，让消费者无从核对。

## 二、针纺线（内衣、内裤、袜子）反复出基础安全项

| 时间 | 抽查 | 产品 | 问题 |
| ---- | ---- | ---- | ---- |
| **2014-10** 质检总局针织内衣**电商**专项抽查（35 批，17.1% 不合格） | 商标"七匹狼"**男士纯棉内衣** | **pH 实测 9.2**（标准 4.0–8.5，属强制性安全指标） |
| ↑ 同上，**生产企业** | **浙江开倜服饰有限公司** | **不是七匹狼自有工厂**——针纺线授权/代工的证据 |
| **2014-01** 天津滨海新区工商 袜子监测 | 七匹狼 一款袜子 | **pH 值不合格**（4 个品牌之一：情怡、F&F、汶权、七匹狼） |
| **2010** 北京市工商局 服装抽检（65 种不合格，全市下架） | 七匹狼 **女 POLO 领短 T 恤衫** | **纤维含量**不合格（成分标注误导） |
| **2015-03** 广州市工商局 流通领域服装（近三成不合格） | 七匹狼 **休闲针织休闲服** | **纤维成分含量 + 耐干洗色牢度**不合格（同批香奈儿牛仔裤、新百伦外套亦被点名） |

**规律很清晰**：**内衣/袜/针织衫这类"针纺"品**（多为授权或代工生产）出的是 **pH、纤维含量**这种最基础的项目；**夹克、外套、休闲裤**（年报口径"部分自制"）反而少出事。

## 三、为什么"七匹狼"三个字特别容易被蹭

1. **2025-04 泉州泉港区市监处罚**：商家在**商品标题用"七匹狼"引流**，产品上并无七匹狼商标 → 被认定为侵权/混淆并处罚。→ **标题带"七匹狼"不等于就是七匹狼**（商标注册证 16801138，权利人福建七匹狼实业，第 25 类含衬衫/裤/夹克/内衣/童装/围巾等）。
2. **2021-12 江门江海区**：查获标"**意大利七匹狼**""意大利七匹狼服饰集团有限公司（授权）"的服装、皮带 **442 件（条）**，罚 1.5 万、全部没收。→ "意大利七匹狼"**不是七匹狼**，是攀附品牌。
3. **2024-07 广西上思县 七匹狼皮鞋专卖店**：发布"关店降价、打折"广告**未注明活动期限**，整改后仍继续 → 按虚假广告处罚（广西 2024 年度典型案例）。→ "最后三天/关店清仓"式话术有判例在先。

## 四、生产模式（决定你该买哪一类）

2025 年年报原文口径：**"除夹克类、外套类和休闲裤类的部分产品自制生产外，大多数产品是采用外部采购模式进行"**；另有"直发代销"模式（公司直接下单生产配发终端）。主标"七匹狼"之外还经营国际轻奢 **Karl Lagerfeld**。
→ 含义：**主标夹克/外套/休闲裤是它自己把关最紧的品类**；其余（尤其针纺、配饰、鞋、皮具）更多是采购/授权，质量方差大。

## 五、不能买 / 要少买

1. **旗舰店的围巾、围脖、手套、帽子等配饰**——2021 年就出在旗舰店，且 96% 羊毛实测 0 羊毛。
2. **七匹狼内衣、内裤、袜子**——pH 9.2、袜子 pH 不合格都有官方记录，生产方是浙江开倜等外部企业。
3. **吊牌写"波斯纶""珍珠纤维""大豆纤维""牛奶纤维"的款**——不是 GB/T 4146 法定纤维名称，正是 2021 那次被判定不合格的直接原因；看吊牌只认法定名称（聚酯纤维/腈纶/锦纶/羊毛/羊绒/桑蚕丝…）。
4. **商品标题带"七匹狼"但实物无吊牌无商标的**（泉州 2025 判例）；以及"**意大利七匹狼**"（江门 2021 没收 442 件）。
5. **"关店清仓/最后三天"话术款**（上思县 2024 虚假广告处罚）——打折力度越大越要核对标签与实物是否同款。
6. **儿童款不认安全类别**——七匹狼童装属第 25 类注册范围，但给孩子买只看 **GB 31701 A 类**（婴幼儿）或至少 B 类，不看品牌。
7. **详情页"检测报告"当唯一依据**——2021 年那份报告就缺纤维含量、甲醛、pH、偶氮四项。

## 六、三条验货

1. **吊牌纤维名称逐个对照法定名称**：看到"波斯纶"这类非规范名，等于告诉你"这批标注不规范"。
2. **买针纺先看安全类别与 pH 风险点**：内衣内裤选 A 类/B 类且标注齐全，深色、免烫、抗皱款（树脂整理）pH 偏移风险更高，新衣先洗一遍。
3. **标题验真**：拿到手看**领标 + 吊牌 + 洗水标**三处商标是否一致，商标注册号可查；不一致直接退。
