# 少买——山寨 / 碰瓷品牌（小作坊仿冒名牌）

> 口径：不是"贴牌授权"，也不是"假冒伪劣假货"，而是**名字和包装故意模仿大品牌、让你以为是名牌**的小作坊产品。
> 多出现在农村小卖部、乡镇超市、拼多多低价区、春节走亲戚的礼盒里。
> 买之前多看一眼包装上的字，别被"长得像"骗了。

## 怎么辨别

1. **多看一个字**：拿起来先读名字，别光看包装配色。
2. **看生产厂家**：正品生产厂家你听过（康师傅=天津顶新、大白兔=上海冠生园、六个核桃=河北养元）；山寨的厂家名你从没听过，地址在某县某镇。
3. **看价格**：比正品便宜一半以上的，大概率有问题。
4. **看渠道**：农村大集、乡镇小卖部、拼多多 9.9 包邮的礼盒，是山寨重灾区。
5. **春节礼盒**：走亲戚送的礼盒，4 箱里 3 箱是山寨的情况很常见。
