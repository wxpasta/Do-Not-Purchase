# 电动自行车（小电驴）：哪些不能买

> 口径：市场监管总局 2026-11-27 集中约谈通报、GB 17761—2024 问答、2026 年吉林/广州/北京抽检与执法案例、缺陷产品召回公告。
> **一句话结论**：**别按牌子挑，按"型号 + CCC + 一车一池一充一码"挑**——2026-11-27 市场监管总局一次约谈的 15 家，就是市面上几乎所有叫得出名字的品牌（雅迪、台铃、爱玛、新日、小刀、绿源、金箭、九号、小牛、绿佳、绿驹、立马、极跃、赛鸽、极核），原因是 CCC 全覆盖飞行检查发现**"违反强制国标出厂销售不合格产品"**。品牌名字已经不构成质量保证。

## 一、硬时间线：这四类车现在不能买

| 时间点 | 规则 | 含义 |
| ---- | ---- | ---- |
| **2025-09-01** | GB 17761—2024 实施，全面替代 2018 版 | 此后生产必须是新国标车 |
| 2025-09-01 起 | **不得生产**不符合新国标、未取得 CCC 认证的车 | — |
| 2025-11-01 起 | 电动自行车用**锂离子蓄电池、充电器**必须 CCC 认证并标注标志 | 电池/充电器单独也要有 3C |
| **2025-12-01** | **旧国标车全面禁售**（旧标车销售过渡期只到 11-30） | 现在还在卖旧标车 = 违规 |
| 2026-11-27 | 15 家主流企业被约谈，要求"缺陷产品立即召回" | 说明市面仍有不合格在售 |

**新国标四条硬指标（缺一条就是不合规车）**：
1. **塑料总质量 ≤ 整车质量 5.5%**（防火阻燃，鞍座/电池盒高阻燃，挡泥板铝镁合金）；
2. **整车质量**：铅酸电池车型 ≤ **63 kg**（原 55 kg 放宽），锂电池车型仍按 **55 kg**；
3. **防篡改**：电池组、控制器、限速器三处，含 6 类防篡改检查方法；最高设计车速仍为 **25 km/h**；
4. **北斗定位 + 通信与动态安全监测**；且执行"**一车一池一充一码**"（车、电池、充电器、码一一对应，互认协同充电）。

| 同上 | **雅迪**（天津雅迪实业） | **TDT1664Z** | 互认协同充电 |

| 北京 2026 执法 | 台铃（安家兴洲商贸） | **TDT7002Z** | 门店**改装电池连接线路**、装配电池类型与合格证不符，罚 4 万元 |

**读法**：这些型号的共同点是**"互认协同充电 / 电池组防篡改 / 整车质量"**——都指向同一件事：**这台车的电池可以被换、被改、被配错充电器**，而电芯/充电器不匹配正是电动自行车起火的头号原因。

## 三、召回车（买了要退/要修）

- **天津神州行电动车**召回「**神州行、凤凰、吉祥狮**」多型号：TDT-248Z/246Z/256Z（**蓄电池防篡改**不符）、TDT-218-1Z/218-2Z（反射器照明鸣号、标识警示语、互认协同充电、布线）、TDT-257Z（**整车质量、尺寸限值、蓄电池防篡改**，存在被改装风险）。
- **南京博兰得**召回 2025-11-14 生产的「**九号**」DZL483004 **锂电池充电器 1500 件**：超温保护不符 GB 42296—2022，**70℃ 以上可能不退出充电模式**，内部元件持续高温、熔化绝缘层→可能引发火灾。

→ 教训：**充电器也在召回范围**，不是只有车。

## 四、不能买（清单）

1. **旧国标车（GB 17761—2018）**——2025-12-01 起禁售；现在任何在售"旧标清库车"都不合规，也上不了牌。
2. **无 CCC 标志的车 / 无 CCC 标志的锂电池与充电器**（2025-11-01 起强制）。
3. **塑料件多、整车超重**的车型：锂电 >55kg、铅酸 >63kg 一律不合规；广州那台爱玛 TDT6103Z 就是"整车质量"不合格。
4. **电池能随便换、充电器不互认的型号**：不合格项集中在"电池组防篡改""互认协同充电"——这类车天生给改装留了口子。
5. **门店现场"加装/改装"的车**：北京三个案例（绿源改电池接口线束、台铃改电池连接线并装错电池类型、雅迪整车质量超标）全是**门店动手改的**，罚 3–4 万。**店里帮你"解速""换大电池""加长坐垫"= 你买的是一台不合格车 + 一张废合格证**。
6. **600 元级"低价改装车"**：北京朝阳案，进价 **600 元/辆**、卖 1250 元，车宽/座椅长度/电池电压多项不符，还**伪造号牌配套卖**；四川"米韵"电动自行车被查**车速限值、过流保护、蓄电池防篡改**三项不合格。
7. **杂牌/白牌/无生产资质厂的车**：CCC 飞行检查查的就是"产品一致性"，小厂最经不起查。
8. **梯次利用/拆机电芯的"换电套餐"**、非原厂大容量电池——不在车厂备案体系内，出事保险与责任都算你的。
9. **网上"免上牌""包上牌"话术**：约谈通报专门点了"**不得误导消费者无牌上路行驶**"，这句出现在监管文件里，说明是普遍套路。

## 五、反向事实（别一棍子打死）

- 新国标不是"越改越差"：**放宽了铅酸车重量上限（55→63kg）、不再强制装脚踏**，同时把防火阻燃、防篡改、制动距离三项收紧了——**买新标车整体更安全**。
- 主流大厂被约谈不等于全线不合格：飞检针对"**产品一致性**"（量产车与认证样车是否一致），问题多在**特定型号/特定批次/门店改装**。所以正确姿势是：**查具体型号，而不是查品牌口碑**。
- 已有车不会被强制淘汰（已购旧标车由各地以旧换新政策引导更新），**能骑，但别指望它合规上路不被查**。

## 六、三条验货

1. **三处扫码对码**：车身码、电池码、充电器码——能否"**一车一池一充一码**"互认；对不上就是拼装/换过件。
2. **看合格证 + CCC**：整车 CCC 标志、锂电池与充电器各自的 CCC 标志；合格证上的**型号**要和车架铭牌一致（吉林/广州那些不合格车全是"型号不符或项目不符"）。
3. **当场拒绝三件事**：解速、换大电池、加长坐垫/加装雨棚。任何一项做了，这台车就变成不合格产品，且事故责任在你。
