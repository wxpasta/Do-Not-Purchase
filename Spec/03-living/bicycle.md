# 自行车：哪些不能买

> 口径：市场监管总局 2026-12-01 实施的两项自行车国标、GB 46517—2025 儿童骑行用品强制国标、缺陷产品召回公告、上海市场监管局儿童用品典型案例。
> **一句话结论**：**成人车看"装配"、儿童车看"CCC + 全链罩 + 手闸"，二手看"碳架暗伤"**。2026 年 11–12 月两个新国标接连生效，此时买"低价整车""无型号儿童车""二手碳车"，正好撞在监管收紧的窗口上。

## 一、刚生效 / 即将生效的两个国标（直接当尺子用）

| 标准 | 生效 | 管什么 |
| ---- | ---- | ---- |
| **GB 46517—2025**《儿童骑行及活动用品 通用安全要求》（**强制性**，新制定） | **2026-11-01**（本月已生效） | 儿童自行车、儿童三轮车、独轮车、儿童电动滑板车；机械物理、特殊结构、热危险与燃烧、材料化学、电气、辐射、标识说明 |
| 配套 **GB/T 14746—2025**（儿童自行车）、GB/T 14747—2025（三轮车）、GB/T 46507—2025（电动滑板车） | 2026-11-01 | 单品专项安全要求，取代 GB 14746—2006 |
| **GB/T 3566—2026**《自行车装配要求》 | **2026-12-01** | 车闸操控与制动可靠性、链条/传动带**松垂限值**、车架车把连接锁紧指标（防松动脱落） |
| **GB/T 19994—2026**《自行车通用技术要求》 | **2026-12-01** | 山地/公路/城市旅行车；车架几何、车轮规格、传动比；**制动性能、转向操控、车轮静负荷强度** |

→ **买之前只要问一句"执行哪个标准"**：成人车能答 GB/T 19994—2026（或旧版 GB/T 19994—2008）+ 装配标准；儿童车要能答 GB 46517—2025 / GB/T 14746—2025，并且**有 CCC 标志**（童车属强制认证目录）。答不出来的，就是"无型号整车"。

## 二、被实锤的产品（这些型号别买）

| 产品 | 问题 | 结果 |
| ---- | ---- | ---- |
| **上海永久「小蚂蚁」12 寸儿童自行车**（2024-12-12～2025-06-19 生产，批号小蚂蚁-12-2025） | **手闸性能试验不符合 GB 14746—2006**，制动受影响 | **召回 7 辆**，2026-03-27～06-26 退货处理 |
| **上海永久**另一款儿童自行车（上海市市场监管局儿童用品典型案例，2026-08 通报） | **手闸（刹车）功能存在缺陷，不符合国家标准** | **行政处罚**（同批被点名的还有乐扣乐扣蘑菇咬胶、宝大祥牛仔背带裤绳带） |
| **上海凤凰 FH-L-1206「荣耀升级版」儿童自行车**（2022-04-20 生产） | ①**把横管把套拉脱力不足 70N**（骑行中把套可能被拉脱致摔伤）；②**鞍座最大高度 <560mm 却无全链罩**（儿童肢体易被链条夹伤） | **召回 410 辆**，门店退货 |
| **深圳创新维 JAVA-NEO / SABBIA 折叠车**（2026-04-01～2026-08-25 购买批次，NEO-349/406-AL、-ALD、-CB 等） | **刹车手柄装配反了（左前右后）**，制动操控异常 | **主动召回**，免费检查并更正装配 |

**这四条的共性**：出问题的都不是"车架断了"这种大件，而是**刹车（手闸、把套、左右手刹顺序）**——恰恰是出事时唯一救命的部分。所以验车第一步不是看变速、看重量，是**看刹车**。

## 三、不能买（清单）

### 成人车
1. **无品牌、无型号、无执行标准的电商低价整车**（尤其"199 元山地车""包邮公路车"）——装配公差与制动是第一批被省掉的东西。
2. **装配可疑的车**：链条松垂到会掉链、变速换挡卡顿、车把/车架锁紧后仍能晃动——GB/T 3566—2026 专门管这三样，说明是行业普遍问题。
3. **折叠车"快拆"款不做锁紧检查**：JAVA-NEO 那批就是装配环节出错（左右手刹装反），买折叠车必须当场捏前后刹验证。
4. **二手碳纤维车架（无事故记录、无检测）**：碳架暗伤肉眼不可见，落地一次就可能失效；二手碳车只买能提供原厂检测/维修记录的。
5. **二手"电改""油改"车、无发票无车架号的车**：来源不明，出事故无法追溯。

### 儿童车（重点）
6. **无 CCC 标志的儿童自行车/三轮车/平衡车**——童车属强制认证，没有就是不合格品。
7. **鞍座最大高度 <560mm 但没有全链罩的**——凤凰召回就是这条；孩子脚会被链条夹。
8. **把套能"一拽就掉"的**——标准要求承受 **70N 拉脱力**，当场拽一下就能验。
9. **手闸捏不动 / 捏到底不抱死的**（永久两次被点名都是手闸）。
10. **带尖锐突出物、无任何标识与警示语的**（GB 46517—2025 新增特殊结构与标识要求）。
11. **没有说明书、没有"适用年龄/体重"标注的**。

### 头盔
12. **无 GB 811—2022 标识的头盔**（2023-07-01 起强制）：A 类＝摩托车+电动自行车通用，**B 类仅限电动自行车乘员**，别拿 B 类给孩子骑自行车用。
13. **12 岁以下戴成人重盔**：标准说明书本身提示"**12 岁以下儿童宜选用质量轻的头盔**"。
14. **二手/摔过一次的头盔**：标准明确"发生过一次较大撞击事故应停止使用"。
15. **无 3C 标志的"网红轻盔""几十元头盔"**——缓冲层厚度与吸收碰撞能量是硬指标，便宜盔省的就是这层。

## 四、反向事实（别一概而论）

- **出问题的是型号不是品牌**：永久、凤凰都是老牌，召回原因是**特定型号/特定批次的手闸、把套、链罩**，且**都是主动召回 + 免费退货/更正**——这比不召回强。
- **标准在变严不是变麻烦**：GB 46517—2025 是"通用底线 + 单品专项"两层体系；GB/T 3566/19994—2026 把装配和整车性能都写细了，**合规成本上升，但便宜车的漏洞会被堵**。
- **成人自行车不在 CCC 目录**（只有童车、电动自行车在），所以成人车"没 3C"不算违规，但也意味着**没有强制门槛，只能靠标准号 + 装配验收**。

## 五、三条验货（买车现场 5 分钟）

1. **刹车三连**：捏前刹推车——后轮是否离地不打滑？捏后刹推车——车是否不动？**确认"左后右前"或与标注一致**（JAVA 那批就是装反）。
2. **拽把套 + 看链罩**：双手用力拽把套，能动/能脱＝不合格；儿童车鞍座 <560mm 必须有全链罩。
3. **查三样文字**：执行标准号（成人 GB/T 19994 / 儿童 GB 46517 或 GB/T 14746）、儿童车 CCC 标志、头盔 GB 811—2022 与 A/B 类标识。
