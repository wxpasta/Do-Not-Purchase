# 雅迪（Yadea）：哪些不能买

> 口径：雅迪＝雅迪控股（01585.HK）＋天津雅迪实业、浙江雅迪等生产主体。**品牌最稳（资产负债率 10.4%、现金 71 亿），但"卖法最乱"**：处罚型号多、经销商自行改座椅、超 4 万家门店压货。
> **一句话结论**：**不买加长座/改装座车、不买被处罚过的型号、不买生产日期超一年的库存车、不在临时促销点/串货渠道买、充电器只用原厂。**

## 一、被处罚过的型号（这些别买）

| 地点·时间 | 型号 | 问题 | 处理 |
| ---- | ---- | ---- | ---- |
| **株洲（2025-10）** | **TDR3119Z（5 台）、TDR3091Z（6 台）、TDR3133Z（5 台）** | 不合格 | **没收 16 台 + 罚 57484 元**（株市监处罚〔2025〕18 号） |
| **桂平（2025-10）** | **TDR3124Z** | 不符合国家标准 | 没收 2 辆 + 罚 8998 元 |
| **桂林（2026-07）** | 雅迪牌 1 辆（整车编码 214522620286519） | 不合格 | 罚 550 元 + 没收 |
| **保定清苑（2025-09）** | **TDT1479Z 等 8 辆**（均从天津雅迪实业进货） | **经销商擅自把座椅改成 600mm**，超 GB 17761 鞍座 ≤350mm；"加长座椅改变重心、影响整车平衡" | **罚 19000 元** |
| **北京（执法）** | **TDR3073Z、TDR3497Z** | 整车质量 | 罚 **30792 元**（见 [e-bike.md](e-bike.md)） |
| **吉林（2026 抽检）** | **TDT1664Z**（互认协同充电）、**TDT1617Z**（互认协同充电 + 整车质量） | 不合格 | 通告（见 [e-bike.md](e-bike.md)） |

注意保定案的性质：**不是厂家出厂就超长，是经销商进货后自己改的**。这意味着"加长座"在渠道端是普遍手法——你在店里看到的"能坐两个人"的车，很可能就是改过的。

| 时间 | 型号 | 数量 | 缺陷 |

| **2020-07**（总局公告） | **TDT1126Z**（2019-02～2020-06 制造） | **11273 辆** | 骑行脚踏与后座乘客支撑脚踏间隙不合理，**倒车时脚踏随动反转，可能夹伤后座乘客脚面** |

→ TDT1126Z 是 2019–2020 年的车，**二手市场仍有**；充电器召回的批次仍在配件渠道流通。

## 三、2026-11-27 约谈：多了三条对你有利的承诺

15 家名单**雅迪排第一**。约谈要求里有三句可以直接当维权话术用：
1. **不得推诿责任**；
2. **不得误导消费者无牌上路行驶**；
3. **不得要求折价退车、不得以"证书很快恢复"为由拒绝退车**；
4. 经调查认为存在缺陷的产品，**应立即实施召回**。

## 四、公司层面：最稳的财务，最难的销量

| 指标 | 2026 上半年 |
| ---- | ---- |
| 营业收入 | **182.36 亿元（-5.0%）** |
| 归母净利润 | **12.01 亿元（-27.2%）** |
| 毛利率 | 19.6% → **17.7%** |
| **电动自行车销量** | **666.55 万台 → 414.81 万台（-37.8%）**，收入占比 48.5%→34.3% |
| 电动踏板车 | 348.42 万台（**+63.7%**），收入占比 19.8%→35.3% |
| 经营现金流净额 | 47.27 亿 → **16.26 亿（-65.6%）** |
| 存货 | 较 2025 年末 **+25.9% 至 17.96 亿元** |
| 应收账款 | 4.70 亿 → **10.07 亿（+114%）** |
| 现金及等价物 | 71.23 亿元；**资产负债率仅 10.4%** |
| 门店 | **超 4 万家**（密度过大、经销商利润薄） |

含义很清楚：**公司不会倒（现金 71 亿、负债率 10.4%），但渠道在承压**——存货涨、应收翻倍、门店过密、单车利润薄。这种结构下，终端最常见的动作是：**降价清库存、推高毛利改装件、跨区串货、临时搭台促销**。

## 五、不能买清单

1. **鞍座超 350mm 的"加长座/双人座"车**（含经销商自行改的 600mm 座椅）——上牌、保险、责任认定三头堵。
2. **上表被处罚型号**（TDR3119Z、TDR3091Z、TDR3133Z、TDR3124Z、TDT1479Z、TDR3073Z、TDR3497Z、TDT1664Z、TDT1617Z）。
3. **召回型号 TDT1126Z**（2019–2020 年的二手"准新车"）。
4. **生产日期超过 12 个月的库存车**：铅酸电池会硫化、锂电长期存放掉容量，且厂家三包按"生产日期/激活日期"算，容易吃掉质保。
5. **临时促销点、展会摊、无授权牌的门店**：4 万家门店里授权与非授权混杂，出问题找不到主体。
6. **跨区串货车**：便宜几百块，但本地售后不认、CCC 与"一车一池一充一码"难核。
7. **散装/二手/非原型号充电器**（含上述召回批次）。
8. **"解限速、换大电池、加后座"的改装车**：三包直接失效，起火与事故责任自负。

## 六、反向事实

- **雅迪是这批企业里财务最稳的**：现金 71.23 亿元、资产负债率 10.4%、毛利率仍在 17.7%。
- **产品结构在主动切换**：电动自行车 -37.8%，但电动踏板车 +63.7% —— 新国标下"自行车形态"需求萎缩，不是质量崩了。
- **召回是主动行为**：2020 年 11273 辆脚踏缺陷召回，是总局公告、免费维修，比不召回强。

## 七、三条验货

1. **带尺子量鞍座**：>350mm 直接走；同时看座椅是否有二次改装痕迹（螺丝新、包皮不服帖）。
2. **看生产日期 + 查型号**：车架铭牌生产日期是否超 12 个月；型号是否落在处罚/召回清单。
3. **要发票 + 扫"一车一池一充一码"**：发票主体须为授权经销商，扫码核对电池、充电器是否原配。
