# 小牛电动（NIU）：哪些不能买

> 口径：小牛电动＝江苏小牛电动科技有限公司（纳斯达克 NIU）。**不是"品牌要倒"，是"具体型号 + 买法"有问题**：抽检黑榜点名到型号，售后政策对老车不友好，亏损期靠降价和扩店走量。
> **一句话结论**：**不买抽检不合格型号的同批次（TDR174Z / TDR84Z / TDR112Z 等）、不买停产老款清仓车、不在非授权店买、充电器只用原厂。**

## 一、被官方点名的型号（这些别买）

| 型号 | 谁通报 | 不合格项目 | 时间 |
| ---- | ---- | ---- | ---- |
| **TDR174Z** | 合肥市市场监管局（受检：合肥包河区东韩电动车商行） | **电池组防篡改** + **互认协同充电**（两项都是防火、防非法改装的核心强制指标） | 2026-10 通报（检样 2026-05-15） |
| **TDR84Z** | 福建省市场监管局 | **整车质量** | 2025-06 |
| **TDR112Z** | 湖南湘江新区市监局行政处罚（湘新商市监处罚〔2025〕043 号） | **整车质量、尺寸限值**；经销商整改报告称"生产厂家出厂时未把控" | 2025-01 |

补充：北京、温州等地市场监管公告显示，小牛**多款型号**在"充电器与蓄电池防篡改""电气装置""整车质量""尺寸限值""反射器安装"等项目存在不同程度不符合项（中国报道 2025-06 汇总）。

**怎么理解这两项不合格**：
- **电池组防篡改不合格**＝结构上没堵死私自扩容、换高压电池、改装提速的空间 → 一旦被改装，起火风险直接上升。
- **互认协同充电不合格**＝电池和充电器不做信息识别就能充 → 混用非标充电器时没有最后一道保护。

## 二、公司层面：亏损，不是倒闭

| 指标 | 数据 |
| ---- | ---- |
| 2026 上半年 | 营收 23.50 亿元，**净亏损 1.96 亿元**（归母同为 -1.96 亿） |
| 2026 二季度 | 营收 14.404 亿元（+14.7%），销量 43.47 万辆（+24.2%），**净亏损 1.02 亿元**（去年同期净利 588 万元） |
| 单车均价 | 2025 年 3614 元（此前连续三年下滑，仅小幅回升 2%） |
| 门店 | 2026-06-30 中国 4570 家；2026-09-30 **4740 家**（仍在扩店） |
| 行业 | 2026 上半年电动两轮车内销 2825.2 万台，**同比 -12.6%** |

含义：**亏损期靠"降价 + 扩店"走量**——对消费者意味着两个风险：①清库存的老款/滞销款会被大幅打折，②加盟门店比例上升，售后水平参差。这跟"公司明天倒闭"是两回事。

## 三、2026-11-27 被总局约谈

市场监管总局对 15 家电动自行车企业集中约谈，**小牛在名单内**（雅迪、台铃、爱玛、新日、小刀、绿源、金箭、九号、小牛、绿佳、绿驹、立马、极跃、赛鸽、极核）。约谈缘由：CCC 认证全覆盖飞行检查发现"部分企业存在违反强制性国家标准出厂销售不合格产品"。

## 四、售后政策里的两个坑（官方页面原文）

1. **老车型零部件已停产**：官方《保外零部件换件指导价》写明"部分老车型零部件已经停产，工厂提供的维护品（WH）为维修之后的性能正常部件，外观可能会有一定瑕疵，**折扣价供应，更换后不提供三包服务**"。→ **停产老款 = 修得上但没三包**。
2. **电池存放有硬限制**：保修免责范围包括"整车插电放置超过一个月、单独存放起始电量低于 50% 且超过 3 个月"未及时充电导致的损坏。→ 长期不用必须按 50% 电量、3 个月内补电。

## 五、不能买清单

1. **上述型号的同批次车**（TDR174Z、TDR84Z、TDR112Z）——尤其二手市场里的"低价准新车"。
2. **停产老款清仓车**——零部件停产、WH 件不三包，二手残值也差。
3. **非授权店/纯线上"无票车"**——无法确认 CCC 证书、电池是否原配、"一车一池一充一码"是否对应。
4. **散装/二手充电器**——2021 年南京博兰得曾召回小牛 48V 2.8A 锂电池充电器 **1920 件**（空载输出电压超标、无说明书、缺防雨淋警示）；这类充电器在二手平台仍在流通。
5. **私自扩容/换大电池的"改装车"**——防篡改项目本来就是拦这个的，改装后起火风险与保险、责任认定全部自己承担。
6. **"智能功能"当卖点溢价买**——小牛均价已连续下滑，智能功能不是安全指标，别为它多付钱。

## 六、反向事实

- **抽检不合格是"单批次单型号"**，不是全系不合格；合肥那次 490 组样品合格率 **98.37%**，小牛是其中之一。
- **小牛仍是少数全系有 BMS 保护的量产车**：说明书明确 BMS 实时采集单体电压、总电压、电流、温度，异常时切断主回路。
- **门店在增加**（4570→4740），售后网点密度仍高于多数新势力品牌；亏损是行业性的（上半年行业销量 -12.6%）。

## 七、三条验货

1. **对型号**：看合格证与车架上的型号，是否落在 TDR174Z / TDR84Z / TDR112Z；在"一车一池一充一码"平台核验电池与充电器是否原配。
2. **查 CCC 与发票**：CCC 证书编号与车型一致、发票开具主体是授权经销商；非授权店一律不买。
3. **只买在产款 + 原厂充电器**：问"这款还在产吗、零部件有货吗"；充电器只买原厂同型号，不碰散装与二手。
