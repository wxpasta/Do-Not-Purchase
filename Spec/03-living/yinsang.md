# 银桑（浙江银桑丝绸家纺）：哪些不能买

> 口径：上海市质监局 2014 年蚕丝被专项抽查原始汇总表、浙江省 2018 年蚕丝被质量比对、电商在售页参数、工商风险页。
> **先给结论**：银桑有**一次被点名**——2014 年上海市质监局专项抽查（38 批 18 批不合格、不合格率 47.4%），它的"蚕丝被 200×230cm 货号 C1520"（浙江银桑丝绸家纺，购自上海松江商城）**不合格项目是"使用说明（标签）"**，属于标识标注问题，**不在质量指标（pH／纤维含量／含油率／偏差率／填充物品质）不合格那张表里**。此后未见新的官方点名；企查查显示**行政处罚 2 条**（内容未公开，待官方定性）。它真正要防的是**"标签/参数不写清"的延续问题**和**桐乡洲泉产业带的低价同名店**。

## 一、官方记录

| 时间 / 抽查 | 样品 | 结果 |
| ---- | ---- | ---- |
| 2014 年 上海市质监局蚕丝被专项抽查（38 批，18 批不合格，47.4%） | 银桑 蚕丝被 **200×230cm，货号 C1520**，浙江银桑丝绸家纺有限公司，受检单位 上海松江商城 | **不合格：使用说明（标签）**（当批 12 个批次同项不合格之一） |
| 同上批 质量指标不合格表（pH／含油率／质量偏差率／纤维含量／填充物品质，共 14 批） | — | **银桑不在其中** |
| 2018 年 浙江省蚕丝被质量比对（省内 45 家 45 批） | 全省 2 批不合格 | 公开报道未点名银桑 |
| 企查查 / 天眼查 | 浙江银桑丝绸家纺有限公司 | **行政处罚 2 条**（企查查）／行政处罚警示 1 条（天眼查），**内容未公开，待官方定性** |

**"使用说明（标签）不合格"要怎么看（不夸大也不轻放）**：
- 它不是掺假、不是 pH 超标，是**吊牌/水洗标信息不全或标注错误**（当年这批里 12 个批次栽在同一项，属行业通病）。
- 但标签恰恰是消费者唯一的判断依据——**不标丝绵长度、不标桑蚕/柞蚕、不标净重，等于把验货门槛全推给买家**。2014 年栽在这项，说明这是它的弱项，不是偶发。

## 二、电商在售页现在还在犯同一个毛病

苏宁"银桑官方旗舰店"在售款「正品蚕丝被 100 桑蚕丝 空调被 夏凉被」（150×220／180×230／200×230，白色 6 斤）商品参数栏写的是：

| 参数项 | 页面写的 | 问题 |
| ---- | ---- | ---- |
| 面料 | **纤维** | 化纤面料，不是棉、不是真丝 |
| 填充物成分 | **蚕丝** | 没写桑蚕丝还是柞蚕丝、没写比例、没写丝绵长度 |
| 制造工艺 | 绗缝 | — |
| 被子总重量 | 1 斤以内 | 与标题"6 斤"对不上，参数与商品描述不一致 |

GB/T 24252—2019 要求标明**填充物种类、丝绵长度、净重**。参数栏这种写法，是 2014 年那项"标签不合格"的延续版。

## 三、品牌身份（企业口径，不等于单件质量）

- 浙江桐乡**洲泉镇**（"中国蚕丝被之乡"）德胜路 518 号；1998 年成立，曾用名"桐乡市银桑被服有限公司"；注册资本/实缴 500 万；商标 118 条、专利 16 项；企业自述 1978 年夫妻创业、**自称"国家蚕丝被标准起草单位之一"**（未见国标起草单位正式名录，按企业口径看待）。
- 2011 年央视曝光桐乡部分企业掺假后，**银桑是洲泉镇发出行业自律倡议的 6 家企业之一**（依诺、银桑、丝园、腾飞、华纳斯、丰邦），承诺"不以劣充优、不偷梁换柱、不短斤少两、不掺其他纤维"。这一条是加分项。
- 2012 年央视再度曝光、两家被查封的企业，**公开报道未点名银桑**，不牵连。

## 四、不能买 / 要少买

1. **面料标"纤维／聚酯纤维"的"蚕丝被"**——化纤胎套盖在身上，等于花钱买丝芯配化纤壳（苏宁页就是这种写法）。
2. **填充物只写"蚕丝"、不写桑蚕/柞蚕 + 比例 + 丝绵长度**的链接，参数和标题还对不上（如标"6 斤"、参数写"1 斤以内"）。
3. **6 斤"100%桑蚕丝"卖化纤价**：长丝绵原料约 300 元/斤，6 斤净丝原料 1800 元起，明显低价只能是短丝、混档或化纤。
4. **桐乡/洲泉一带的同名低价店**：银桑商标 118 条、曾用名多，字号极易被蹭；只认"银桑官方旗舰店"及企业主体"浙江银桑丝绸家纺有限公司"。
5. **拿"中国蚕丝被之乡""标准起草单位""浙江十大品牌"当质量结论**——产地与身份不覆盖你手里这床。
6. **吊牌/水洗标缺项就买**：2014 年它栽的就是这项，别重复踩。

## 五、三条验货

1. **先看面料成分**：要棉（40–60 支以上）或真丝；写"纤维/聚酯纤维"的直接放弃。
2. **拉检测口掏中间层**：连续长丝才叫长丝绵；60cm 以上检测口才够用。
3. **吊牌五要素**：桑蚕/柞蚕 + 丝绵长度 + 净重（公定回潮率）+ 等级 + GB/T 24252—2019 与 GB 18401 安全类别。缺一项，就是 2014 年那类问题。
