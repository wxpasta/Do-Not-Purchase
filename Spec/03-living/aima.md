# 爱玛（AIMA）：哪些不能买

> 口径：爱玛＝爱玛科技（603529，沪市主板），电动两轮车头部企业。**它不是"车不行"，而是"卖法有问题"**：多地查到"加长鞍座"的违规车，召回点名到具体型号，充电器也有召回。
> **一句话结论**：**不买鞍座超 350mm 的"加长座车"、不买召回型号（TDT3187Z / TDR3203Z / TDT3200Z / TDR3183Z 等）、不买散装或非原配充电器、不在非授权店买"空车不含电池"。**

## 一、最实质的问题：鞍座长度超标（"加长座车"）

GB 17761—2024 第 6.1.5.1 条要求**鞍座长度 ≤350mm**——这条是拦"一车带两人"的改装车。多地实测结果是**翻倍**：

| 地点·时间 | 型号 | 实测鞍座长度 | 处理 |
| ---- | ---- | ---- | ---- |
| **北海（2026-09）** | **TDR8226Z**（台州爱玛机车制造，制造日期 2026-06-22） | **640mm** | 立案处罚（桂北铁市监处罚〔2026〕133 号） |
| 同上 | **TDR4001-1Z**（丽水爱玛车业，2026-06-23） | **620mm** | 同上 |
| 同上 | **TDR4002Z**（丽水爱玛车业，2026-06-15） | **620mm** | 同上 |
| **陇川（2025）** | 爱玛牌（26 辆，**空车销售、不含电池充电器**，620 元/辆） | 尺寸限值（鞍座长度）不合格 | 责令停止销售，26 辆更换配件后拆除并监督销毁、恢复原状 |
| **海口（2026-01）** | **TDR6084Z** | 不合格 | **没收 2 辆 + 罚款 4798 元**（海市监美处罚〔2026〕8 号） |
| **桂林（2026-07）** | 爱玛牌 1 辆（整车编码 244122651016877） | 不合格 | 罚款 600 元 + 没收 1 辆 |

**为什么这条最要命**：鞍座超长意味着车辆结构已按"载两人"设计，与 CCC 认证状态不一致。买这类车的实际后果是：**上牌可能被卡、出事故后保险与责任认定可能被质疑"非法改装"、后续年检/路检直接不合格**。

前四项合计即 **3135 辆**。二手市场里这批 2022–2023 年的车仍在流通，**按型号就能排除**。

## 三、充电器召回（安全件）

- **2025-01**：唐泽制动器（天津）召回 **爱玛牌 DZLM4820-01 锂离子电池专用充电器 100 只**（2022-09-30 制造）——**电气间隙、爬电距离偏小，可能绝缘失效，严重可致触电**。
- 同批还有一份召回：唐泽制动器召回**斯波兹曼、爱玛、哈啰、小刀、五星钻豹**等品牌铅酸蓄电池专用充电器**共 4200 只**（DZQS4818-01 等），问题包括电气间隙/爬电距离偏小、**连续骚扰电压与辐射骚扰不符合 GB 4343.1—2018**。

→ 二手平台、配件店流通的"原厂同款"充电器，型号对不上就是风险源。

## 四、2026-11-27 被总局约谈

15 家名单**含爱玛**（雅迪、台铃、爱玛、新日、小刀、绿源、金箭、九号、小牛、绿佳、绿驹、立马、极跃、赛鸽、极核）。缘由：CCC 认证全覆盖飞行检查发现"部分企业违反强制性国家标准出厂销售不合格产品"。

## 五、三包政策里的几个坑（官方原文）

- **锂电池**：0–24 个月换新、25–36 个月换维护；**铅酸普品**只有 0–6 个月换新、7–12 个月换维护。
- **控制器、充电器、显示仪表、调速转把、制动刹把、主线束**：**12 个月**。
- **不属于三包**的典型情形：**电池亏电存放 20–30 天必须充电 1 次**，否则不予三包；**未在爱玛指定网点维修、自行改装**；**使用不匹配充电器**；**无维修卡、发票或卡不符**；私自改装。
- 换句话说：**"便宜车 + 自己找修车铺 + 网上买充电器"这套组合，会主动放弃三包。**

## 六、公司层面：仍在赚钱，但在新国标阵痛期

| 指标 | 2026 上半年 |

| 营业收入 | **114.40 亿元（-12.21%）** |
| 归母净利润 | **6.65 亿元（-45.15%）**；扣非 5.98 亿元（-49.45%） |
| 毛利率 | 17.43%（同比 -1.8pct） |

含义：**利润腰斩、现金流为负、渠道压货压力大**——这种阶段最常见的动作就是**降价清库存**。清的多是旧国标车、滞销款、加长座车。**"便宜"本身就是信号**。

## 七、不能买清单

1. **鞍座实测超 350mm 的"加长座车"**（TDR8226Z、TDR4001-1Z、TDR4002Z、TDR6084Z 等已被查型号）——上牌、保险、责任认定三头堵。
2. **上表召回型号的 2022–2023 年车**（TDT3187Z、TDR3203Z、TDT3200Z、TDR3183Z、TDR3183-1Z）。
3. **"空车销售、不含电池充电器"的低价车**（陇川案就是这种：620 元/辆空车，电池自己配）——电池非原配 = 三包与安全双重裸奔。
4. **非授权店 / 无票车**：查不到 CCC 证书变更、无法追溯"一车一池一充一码"。
5. **散装、二手、非原型号充电器**（含上述召回批次）。
6. **自行加长鞍座、加装后座、改限速的车**——三包直接失效，事故责任自负。

## 八、反向事实

- **爱玛仍是盈利的头部企业**（半年净利 6.65 亿元），门店与渠道密度高，售后网点覆盖好于多数品牌；这不是"要倒闭的品牌"。
- **召回是主动行为**：浙江省市监局公告、企业报告召回计划，并免费处置——比不召回强。
- **鞍座超标多为经销商/渠道端问题**：陇川案是经销商库存与转店车，北海案是零售端在售；**厂家出厂把控与终端违规要分开看**。

## 九、三条验货

1. **带尺子**：现场量鞍座长度，**超过 350mm 直接走**（不用听"能上牌"的说法）。
2. **对型号 + 查证书**：合格证型号是否在召回清单；CCC 证书编号与车型一致；扫"一车一池一充一码"确认电池、充电器原配。
3. **要发票 + 指定网点**：发票主体是授权经销商，后续维修去爱玛指定网点——否则三包形同没有。
