# 九号（Ninebot，689009.SH）：哪些不能买

> 口径：九号＝九号有限公司（科创板 689009）＋九号科技（常州）等主体，Ninebot/Segway 同源。
> **一句话结论**：**九号不是"质量差"，是"被改装得最狠"**——智能化卖点自带改装生态，官方 2025-12 亲自发文禁止加装。不买改装车、不买 TDT147Z、不买 2024 年抽检那 7 个批次对应的老款、不买第三方电池。

## 一、被点名与处罚

| 地点·时间 | 型号/批次 | 问题 | 处理 |
| ---- | ---- | ---- | ---- |
| **全国专项抽查（2024-08，总局）** | **7 个批次** | **标识与警示语、整车质量、充电状态主回路保护、互认协同充电、布线** 共 5 类项目不合格 | 通报（该次全国共 146 批次不合格，涉及雅迪、小鸟、绿源、小牛、九号等） |
| **保定莲池（2026-02）** | **TDT147Z**（制造日期 2025-07-08） | 省级监督抽查不合格（斯坦德检测报告 STD-20250813-002S-7） | **没收 1 辆 + 罚 6000 元**（保莲市监处罚〔2026〕4 号） |
| **海口美兰（2026-01）** | **TDT147Z** | 销售不合格电动自行车 | **没收 2 辆 + 罚 2398 元**（海市监美处罚〔2026〕6 号） |
| **2026-11-27 总局约谈** | 15 家名单第 8 位 | CCC 全覆盖飞行检查发现违反强制国标出厂销售不合格产品 | 约谈、要求整改并立即召回缺陷产品 |

**TDT147Z 是唯一在两个省市被同时点名的型号**——保定、海口都是同一个型号，这不是偶然的个例。

## 二、比处罚更值得注意：改装生态

九号的核心卖点是智能、可玩、社区化，结果是**改装件最丰富、改装率最高**。而九号自己在 2025-12-04 发的倡议书里写得很清楚：

> "车辆的电气系统与机械结构是一个高度耦合的严密整体，对整车的改装、加装、换装（尤其是涉及动力、电池系统等核心部件），都可能破坏这一平衡并带来巨大风险。"

官方同时声明：**2025-12-01 起出厂销售的全系电动自行车均符合 GB 17761—2024**，并要求渠道"**不得提供任何形式的改装、加装、换装方案**"。

含义：**你买到的"官方合规车"，只要被店里或第三方动过电池、控制器、限速，就已经不是它送检的那辆车。** 这也是"一车一池一充一码"要管的事。

## 三、公司层面：增收不增利，单车越卖越便宜

| 指标 | 2026 上半年 |
| ---- | ---- |
| 营业收入 | **143.58 亿元（+22.28%）** |
| 归母净利润 | **10.08 亿元（-18.79%）** |
| 扣非归母净利润 | **9.69 亿元（-26.21%）** |
| 综合毛利率 | 28.6%（-1.8pct）；**电动两轮车毛利率仅 17.3%** |
| 电动两轮车 | 销量 **284.40 万台（+18.87%）**，收入 **74.94 亿元（+9.85%）** |
| 汇兑损失 | **3.71 亿元**（上年同期为收益 2.57 亿） |
| 前三季度（Q1–Q3） | 营收 219.43 亿（+19.32%），归母 **13.51 亿（-24.40%）**，扣非 -32.43% |

两个信号要看清：
1. **销量涨 18.9%、收入只涨 9.9%** → **单车收入下滑**（降价换量、低价款占比上升）；
2. **两轮车毛利率 17.3%，低于雅迪整机 17.7%** → 九号的"高端智能"标签在价格战里已经撑不住溢价。

对比：2026 上半年国内电动两轮车整体销量 **-12.6%**（2825.2 万台），九号逆势增长——**它是"抢份额"的一方，用的是价格和产品节奏**。这对买家是好事（有议价空间），但也意味着**渠道压货、老款清库、以旧换新话术会更猛**。

## 四、不能买清单

1. **任何"已改装/已加装"的车**：换大电池、解限速、加后座、改控制器、换第三方充电器——官方明文"可能破坏平衡并带来巨大风险"，且三包失效、起火责任自负。
2. **TDT147Z**（保定、海口两地抽检不合格被没收）。
3. **2024 年抽检涉及的老款批次**（标识与警示语、整车质量、充电状态主回路保护、互认协同充电、布线 5 项都中过）——买前查型号是否在当年不合格名单内。
4. **第三方电池/第三方快充**：九号电池与整车是协议绑定的，非原厂件在"一车一池一充一码"下无法互认，出问题厂家不认。
5. **"社区改装版""玩家定制版"二手**：这是九号二手市场最大的坑——车况看着新，电芯和控制器全换过。
6. **跨区串货的线上低价车**：九号线上/线下价差大，串货车本地门店常拒修。
7. **库存超 12 个月的老款**（新国标切换期尤其多，2025 年 12 月前的旧标车不得再卖）。

## 五、反向事实

- **九号是这批里唯一逆势增长的整车品牌**：行业 -12.6%，它 +18.9%。
- **官方主动禁改装**：2025-12 两份公开文件（新国标声明 + 禁改装倡议书），态度比多数品牌明确。
- **智能化是真需求**：累计国内出货 1300 万台（截至 2026-07-31），OTA、防盗、定位确实是它区别于雅迪的地方。
- **它不是"抽检最差"的那家**：2024 年那次 146 批次不合格里，九号 7 个批次，绿源 6 个、雅迪亦有份。

## 六、三条验货

1. **查型号 + 制造日期**：型号是否含 TDT147Z；铭牌制造日期是否超 12 个月；扫码核对"一车一池一充一码"三者是否同源。
2. **验有没有被动过**：看电池仓螺丝封条、控制器外壳、APP 里的电池序列号是否与铭牌一致；APP 显示的固件/限速参数是否被改。
3. **只买直营/授权店，且要求书面"不改装、不加装"承诺 + 发票**——九号倡议书原文已要求渠道不得提供改装方案，这句话可以直接拿出来对质。
