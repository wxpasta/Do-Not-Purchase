# 瑞得（杭州瑞得寝具）：哪些不能买

> 口径：北京市消协比较试验原始名单、杭州市拱墅区市监局行政处罚决定书摘要、工商主体信息。
> **先给结论**：瑞得是这批蚕丝被品牌里**唯一有"以不合格产品冒充合格产品"这条处罚定性**的——2022 年杭州拱墅区市监局认定其生产的 0.5kg 薄蚕丝被不合格，没收 5 条、罚款 11890 元、没收违法所得 1198 元；2019 年北京消协比较试验里，它的 2kg 款**压缩回弹性不达标**（压缩率 42.1%，标准 ≥45），且使用说明**未标注制造者地址**。它的模式是"丝胎 + 胎套外购、自己拼装"，不是自有缫丝厂。

## 一、两条硬证据

### 1. 杭州拱墅区市监局 杭拱市监潮处罚〔2022〕042 号（2022-11-29）

| 项目 | 内容 |
| ---- | ---- |
| 案由 | **生产、销售不符合保障人体健康和人身、财产安全的国家标准、行业标准的产品**（处罚定性：**以不合格产品冒充合格产品**） |
| 涉案产品 | 瑞得品牌蚕丝被 **220×240cm、净重 0.5kg、粉色**，共生产 7 条 |
| 成本构成 | 粉色胎套 90 元/条（7 条 630 元）＋ 0.5kg 丝胎 440 元/条（7 条 3080 元）；**丝胎与胎套均于 2021-12-26 从桐乡购进**，由当事人自行拼装成被 |
| 查获 | 2022-09-26 现场检查，仓库剩 5 条未售 |
| 处罚 | 没收 5 条；**罚款 11890 元**；没收违法所得 **1198 元** |
| 线索来源 | 2022-03-30 杭州市市监局委托第三方，对**瑞得（建德）蚕丝研究发展有限公司京东店铺**的商品抽检 |

### 2. 北京市消协 2019 年蚕丝被比较试验（50 种样品，40 种全项合格）

| 品名 | 标称企业 | 规格 | 购样地点 | 不合格项 | 实测 vs 标准 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 瑞得蚕丝被（货号 0016020102） | 制造商：杭州瑞得寝具有限公司；品牌运营：杭州瑞得营销有限公司 | 200×230cm，净重 2kg | **天猫 瑞得家纺旗舰店** | **填充物压缩回弹性**；使用说明**未标注制造者地址** | 压缩率 **42.1%**（标准 ≥45）；回复率 98.4%（≥95，合格） |

**这两条要怎么看（不夸大）**：
- 压缩回弹性是"蓬松度/抗压性"指标，不达标**不等于掺假**，但意味着被子压久了回弹慢、容易板结，保暖衰减更快。
- 2022 年那条是**定性最重的一条**：不是"标识瑕疵"，而是"以不合格产品冒充合格产品"；处罚决定书公开摘要里没写具体不合格项目，**具体项待官方全文，不臆测**。
- 两起都发生在**它自己的天猫/京东店铺**，官方店不等于每件都过关。

## 二、它的模式：拼装，不是自产丝

- 制造主体：**杭州瑞得寝具有限公司**（杭州）；品牌运营：**杭州瑞得营销有限公司**；京东店主体：**瑞得（建德）蚕丝研究发展有限公司**（建德乾潭镇黄立垟村，2004 年成立，注册资本/实缴 800 万，法定代表人同为林德方，参保人数 1）。
- 处罚书里写得很清楚：**丝胎、胎套都是外购**（桐乡），自己缝成被。也就是说它的强项是选料和缝制，**不是"从蚕茧到丝绵一条龙"**——所以"源头""自有基地"这类话术对它不成立，验货只能靠实抽。

## 三、不能买 / 要少买

1. **0.5kg 级别的薄夏被、低价"100%桑蚕丝"款**——正是 2022 年被定性"以不合格冒充合格"的那一档（外购丝胎+胎套拼装，最容易被用来贴"100%桑蚕丝"）。
2. **只看"桑蚕丝 100%"、不看"压缩回弹性"的款**——2019 实测压缩率 42.1% 说明它这一档蓬松回弹偏弱，买厚被/冬被尤其要看这项。
3. **使用说明不全的链接/白牌**：未标制造者地址这种问题 2019 年就被点过名；吊牌上没有制造者名称地址、丝绵长度、净重、执行标准、安全类别的，直接放弃。
4. **同名不同主体的"瑞得"**：天猫认"瑞得家纺旗舰店"、京东认瑞得（建德）公司主体；其他店铺/直播间挂着"瑞得"字样，要先核营业执照主体是不是这三家之一。
5. **把"假一赔十/假一赔万"当保障**：只有 2022 年那种被市监局认定的不合格才有退一赔三的法定基础，商家口头承诺不作数，要留订单、聊天记录、吊牌照片。
6. **赠品堆量的套装**：主品往往就是薄被/低克重款，先看净重和等级再谈赠品。

## 四、三条验货（针对它家最该防的两项）

1. **按压回弹测试**：手掌压在被芯上 5 秒后松开，10 秒内回不到原厚度、留下明显压痕的，压缩回弹性大概率不行——冬被尤其要试。
2. **拉检测口掏中间层**：0.5kg 薄被最容易"面子真丝、里子掺丝棉化纤"；从口子往里掏、拉，连续长丝才算长丝绵。
3. **吊牌四要素**：产品等级（优等品/一等品/合格品）、填充物丝绵长度与净重、制造者名称与地址、GB/T 24252—2019 + GB 18401 安全类别。缺一项就别买。
