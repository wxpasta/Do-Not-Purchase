# 博洋家纺（宁波博洋家纺集团）：哪些不能买

> 口径：广州市消委会 2018 年蚕丝被比较试验、北京市工商局 2013 年床品监测、江苏/苏州历次抽查原始名单、黑猫投诉原始页。
> **先给结论**：博洋有**一条性质最重的记录**——2018 年广州市消委会蚕丝被比较试验中，博洋家纺样品**检出禁止使用的"再加工纤维"**（废旧纤维/下脚料再生纤维），**企业随后回函承认"已立即下架相关商品并自查整改"**。这条比 pH、标签问题都重，因为法规明确禁止把再加工纤维用作生活用絮用纤维制品的填充物。另有一次 2013 年北京床品监测不合格（婚庆六件套：使用说明、规格尺寸偏差率）。近年的官方抽查它是合格的。

## 一、硬证据

### 1. 广州市消委会 2018 年蚕丝被比较试验（61 款样品，仅 20 款全项通过）

| 项目 | 内容 |
| ---- | ---- |
| 结论 | 15 款样品原料达不到标准要求，其中 **13 款检出含有禁止使用的再加工纤维**，涉及"南极人、皮尔卡丹、诺澜、**水星家纺**、**博洋家纺**等" |
| 什么是再加工纤维 | 用纤维下脚、纤维制品及其下脚、废旧纤维制品经物理机械工艺再制成的纤维 |
| 为什么重 | 《纤维制品质量监督管理办法》第八条：**不得将废旧纤维制品或者再加工纤维作为生活用絮用纤维制品的填充物、铺垫物原料**；第九条禁止用于内衣、婴幼儿纤维制品 |
| 企业反应 | 广州市消委会将报告寄给企业后，**宁波博洋家纺集团有限公司回函称：已立即下架处理相关商品，并对问题自查、分析及整改** |

**这条怎么读**：不是"罚款通报"，是消委会比较试验（只对样品负责）；但**企业自己回函承认并下架整改**，等于对结果无异议——这在同类证据里分量最重。

### 2. 北京市工商局 2013 年流通领域床品质量监测

- 博洋家纺「**伽蓝的等待**」婚庆床品**六件套**（货号 91106072101）不合格，项目：**使用说明、规格尺寸偏差率**。
- 同批 12 组产品不合格。规格尺寸偏差率的实际后果是：**买回来套不上、被芯装不进被套**。

### 3. 反向事实（近几年是合格的）

| 时间 | 抽查 | 结果 |
| ---- | ---- | ---- |
| 2017 年第 3 季度 江苏省级（85 批，88.2%） | 「舒雅蚕丝春秋被（纯蚕丝被）」200×230、填充 900g，1 号店 | **合格** |
| 2021 年 苏州市级（第 76 期，70 批 97.1%） | 「纯手工桑蚕丝四季被二代」填充 900g，苏州天虹商场 | **合格** |

## 二、注意别混主体

- 博洋是**大集团**：宁波博洋控股集团旗下除博洋家纺，还有服饰等其它品牌（唐狮等），且大量做床品/被芯供应与代工。
- 搜"博洋"口碑时，会把**服饰、酒店布草、代工单**的问题混到家纺头上；认主体"**宁波博洋家纺集团有限公司**"，店铺认天猫/京东"博洋家纺旗舰店"。
- 启信宝显示该公司"自身风险 20 条"（行政处罚等具体条目未公开），**内容不明，不作质量结论**。

## 三、不能买 / 要少买

1. **大促超低价蚕丝被**：再加工纤维几乎只出现在最低价填充里——2018 那次检出就是这条逻辑；价格贴近化纤被的"蚕丝被"直接跳过。
2. **婚庆六件套/床品多件套**：2013 年它栽在"规格尺寸偏差率"，套不上、装不进的概率要自己承担；下单前核对被套/被芯尺寸是否匹配。
3. **绗缝稀疏、无定位点的被芯**：黑猫那条 770 元"跑芯"就是定位不足；买前问清是否**四角定位 + 加密绗缝**。
4. **渠道不认防伪码的订单**：有买家拿着商品自带防伪码仍被拒不承认——收到货先扫码验真并录视频留证。
5. **同款不同价的"专供链接"**：唯品会/直播专场与天猫同款能差 20 元甚至更多，比价后再买。
6. **儿童/婴幼儿蚕丝被挑最便宜的**：法规明确禁止再加工纤维用于婴幼儿纤维制品，这条上必须 A 类 + 有检测报告 + 可开检测口，不能只看牌子。

## 四、三条验货

1. **拉检测口看中间层**：再加工纤维的特征是**色暗、丝短、杂质多、一扯就断**；好长丝绵是乳白色、丝路整齐、能连续拉长。
2. **烧一小撮**：真蚕丝烧毛发味、灰烬一捻即碎；化纤冒黑烟、残渣硬结。
3. **吊牌 + 尺寸**：桑蚕/柞蚕、丝绵长度、净重、等级、GB/T 24252—2019、GB 18401；同时核对被套与被芯尺寸（2013 年那项就是栽在这）。
