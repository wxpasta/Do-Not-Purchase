# 慈云（CIYUN）：哪些不能买

> 口径：只收**苏州市/江苏省市场监管局监督抽查公告**、**在售商品页标注信息**、**公开诉讼记录**。
> **先给结论**：慈云是目前这批蚕丝被品牌里**抽检记录最干净**的一家——2020、2021、2022 三年苏州市级抽查中，被抽到的每一款都是"合格"；2025 年苏州、江苏省级抽查的不合格名单里也都没有它。它的问题不在"被罚过"，而在**在售款存在"宣传长丝、标注绢制丝绵"的落差**，以及**被仿冒**。

## 一、抽检记录（先看它干净在哪）

| 年份 / 抽查 | 慈云被抽样品 | 结果 |
| ---- | ---- | ---- |
| 2020 苏州市级（70 批，合格率 90.0%） | 200×230cm 填充 500g（生产环节）；200×230cm 填充 400g 可水洗凉被（实体店） | 合格 |
| 2021 苏州市级（第 76 期，70 批，97.1%） | 可水洗桑蚕丝凉被 400g（实体店）；纯蚕丝被 500g（生产环节） | 合格 |
| 2022 苏州市级（第 107 期，50 批，98.0%） | 可水洗桑蚕丝凉被 200×230 填充 400g（实体店）；纯蚕丝被 150×210 填充 500g（生产环节）；纯蚕丝被 110×150（天猫） | 全部合格 |
| 2025 苏州市级（第 11 期） | 未出现；2 批不合格是圣宝莱（pH）、上海亿庭（纤维含量） | 未被点名 |
| 2025 江苏省级（104 批 7 批不合格） | 未出现（名单为缔凡、老裁缝、简单睡眠、伊人岛、无印良品等） | 未被点名 |

补充：慈云是 **GB/T 24252《蚕丝被》国家标准的起草单位**、江苏老字号、省级非遗蚕丝被制作技艺传承单位——标准是它自己参与写的，这解释了为什么抽检记录这么稳。

## 二、真正要注意的：在售款的标注落差

以京东在售的**慈云锦云提花蚕丝被（200×230cm，被重约 6 斤）** 商品页"产品信息"为例：

| 项目 | 页面标注 | 该怎么理解 |
| ---- | ---- | ---- |
| 填充物 | 100% 桑蚕丝（**绢制丝绵**） | 丝绵分长丝绵 / 中长丝绵 / 短丝绵 / **绢制丝绵** 四类，**绢制丝绵是最低一档**（短纤维再加工），不是"长丝绵" |
| 产品等级 | **合格品** | 蚕丝被等级为优等品 > 一等品 > 合格品，**合格品是最低等级** |
| 面料 | 100% 聚酯纤维 | 面料不是棉、不是真丝，透气和亲肤性按化纤算 |
| 安全类别 | GB 18401 B 类 | 贴身可用，但不是 A 类婴幼儿级 |

而同一页的宣传素材强调"**100% 双宫茧桑蚕丝**""非遗手工拉制 38 道工序""长丝绵"。**这两套话术不矛盾但容易误解**：双宫茧说的是原料茧，绢制丝绵说的是丝绵形态——花"长丝绵"的钱买"绢制丝绵"，是最容易踩的坑。

## 三、所以哪些不能买

1. **标注"绢制丝绵 / 短丝绵"却按长丝绵价格卖的款**——先看"产品信息"栏，别只看主图文案。
2. **等级只写"合格品"的高价款**——同价位应能买到一等品甚至优等品。
3. **面料 100% 聚酯纤维、却宣传"亲肤透气如真丝"的款**——化纤就是化纤。
4. **非授权店铺的"慈云"**：震泽是全国蚕丝被集散地，慈云 2014 年就在辽宁打过商标侵权官司（诉王敬杰），说明被仿冒是常态；淘宝上大量"慈云旗舰店"近似页面，只认企业主体为"苏州慈云蚕丝制品有限公司"的店。
5. **"可水洗蚕丝被"要谨慎**：慈云有可水洗蚕丝被的发明专利，但可水洗款通常是薄被/夏被，水洗后蓬松度下降是物理事实，别按冬被预期买。

## 四、可以放心买的部分

- 明示"**100% 桑蚕丝（长丝绵）**"+"**优等品/一等品**"+ 公定回潮率 + GB/T 24252 + 净重的款，是它真正的强项（非遗手工拉制、自有桑蚕基地）。
- 抽检连续多年合格，说明**生产端品控稳定**；风险主要来自**渠道仿冒**和**不同价位的用料档次差**。

## 五、三条验货

1. 看"产品信息"栏的四个字：**丝绵长度**（长丝绵/中长丝绵/短丝绵/绢制丝绵）和**产品等级**——这两个词决定价格合不合理。
2. 拉开 60cm 检测口，掏中间丝拉一拉：长丝绵能拉出连续长丝，绢制丝绵一扯就断成短纤维。
3. 核企业主体：店铺营业执照是否为"苏州慈云蚕丝制品有限公司"，不是就是经销/仿冒。
