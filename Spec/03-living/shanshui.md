# 山水丝绸（SHANSHUISILK）：哪些不能买

> 口径：江苏省质监局／苏州市市场监管局抽查公告原始汇总表、京东在售款标注、公司公开资质。
> **先给结论**：山水丝绸有**一次真实的官方点名**——2017 年第 3 季度江苏省抽查，它的"典雅提花桑蚕丝被"（200×230cm，**在自家天猫旗舰店售出**）**面料 pH 值不合格**。此后 2021 年苏州抽查两批全合格，2025 年苏州与江苏省级不合格名单里都没有它。主体产品标注"国标优等品 + 100% 双宫茧桑蚕长丝 + 全棉"，用料在行业里属上游；**真正的坑是"提花/深色胎套的 pH 风险"和"优于国标优等品"这种自拟等级话术**。

## 一、官方记录（一次点名，一次通过）

| 时间 / 抽查 | 样品 | 结果 |
| ---- | ---- | ---- |
| 2017 年第 3 季度 江苏省质监局（85 批，合格率 88.2%） | **典雅提花桑蚕丝被 200×230cm**，标称"山水丝绸"，**山水丝绸旗舰店（电商平台）** | **不合格：pH 值［面料］** |
| 2017 年第 3 季度 同批抽查 | 品质山水桑蚕丝被 200×230cm／填充 500g（生产企业） | 合格 |
| 2021 年 苏州市级（第 76 期，70 批，97.1%） | 贵族蚕丝被 温馨如梦（粉）200×230（生产环节）；同款 150×210（天猫） | 均合格 |
| 2025 年 苏州市级（第 11 期） | 2 批不合格为圣宝莱（pH）、上海亿庭（纤维含量） | 未点名 |
| 2025 年 江苏省级（104 批蚕丝被，7 批不合格） | 名单为缔凡、老裁缝、简单睡眠、伊人岛、无印良品等 | 未点名 |

关键点三个：
1. **不合格发生在它自己的天猫旗舰店**——官方店不等于每件都过关，验货动作不能省。
2. **不合格项是面料 pH，不是填充物**——丝的问题它这批次没被抓到，抓的是胎套染整。
3. 2017 年 85 批里它同时有一件合格一件不合格，说明是**款与款之间的差异**，不是整厂塌方。

## 二、pH 值到底影响什么（这是它最该防的项）

- pH 值指面料/胎套经染色、整理后的酸碱度。国标 GB 18401 规定直接接触皮肤类 pH 在 4.0–8.5；偏酸偏碱都可能**破坏皮肤表面酸碱平衡，引起过敏、发红、瘙痒**（江苏省质监局当年的原话）。
- **风险排序**：深色、大红、深蓝、提花/印花胎套 > 素色本白胎套。染得越重、花型越复杂，pH 控制越难。
- **致命细节**：蚕丝被胎套按吊牌基本都"不可水洗"，也就是说**买回来没法靠洗一次把 pH 降下来**——只能在买的时候选对。

## 三、"优于国标优等品"不是等级

商品页常见"优于国标优等品""特级"字样。事实是 **GB/T 24252《蚕丝被》只有三档：优等品 > 一等品 > 合格品，没有"超优等品"这个等级**，"优于国标优等品"是商家自拟说法，不是第三方检测结论。

- 正确做法：让客服发**检测报告的等级栏截图**，看报告写的是"优等品"还是别的，别看主图文案。
- 它家多数款确实标"国标优等品 + 100% 双宫茧桑蚕长丝 + 全棉提花/60 支全棉"，这个组合本身是合理的；但不标丝绵长度、只写"100% 桑蚕丝"的链接要当心。

## 四、不能买 / 要少买

1. **提花、深色、印花胎套的款给孩子、老人、敏感肌用**——2017 年 pH 不合格就是提花面料；这类胎套又不可水洗，没法补救。
2. **只写"100% 桑蚕丝"、不标丝绵长度（长丝绵/中长丝绵/短丝绵/绢制丝绵）的链接**——标准要求明示，不标就是信息不全。
3. **把"优于国标优等品""特级"当等级买**——要求出示报告等级栏。
4. **非"山水丝绸官方旗舰店"（天猫）或"山水丝绸家纺旗舰店"（京东）的页面**：它家线下只有姑苏区景德路 26-64 号旗舰店、吴江震泽总部展示馆；其他"山水"字号、经销店要打 0512-68623688 核授权。
5. **价格对不上原料的"大斤重长丝"**：长丝绵原料约 300 元/斤，6 斤净丝的被，净丝成本 1800 元起；明显低于这个数，就不是双宫长丝（薄被、混档、短丝除外）。
6. **拿"江苏老字号""国标起草单位""国礼定制"当质量结论**——这些是身份（1929 年震丰缫丝厂传承、FZ/T 41005—2017《蚕丝绵》及缂丝/丝绸床上用品/丝绸围巾标准起草单位、2019 江苏老字号），不覆盖你手里这一件。

## 五、三条验货

1. **先看胎套颜色**：要给孩子/敏感肌就选素色本白、60 支以上全棉；提花款只用于成人、且不贴身。
2. **拉检测口掏中间层**：别只看口边那撮丝，往中间掏、拉——连续长丝才叫长丝绵；同时确认胎套标签写了丝绵长度和等级。
3. **吊牌三件套齐全**：产品等级、填充物丝绵长度与净重、GB/T 24252—2019 + GB 18401 安全类别（A 类可贴身，B 类直接接触皮肤）。
