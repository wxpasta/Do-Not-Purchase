# 恒源祥：哪些不能买

> 口径：国家质检总局网售蚕丝被专项抽查、省市工商/市监抽查名单、新京报梳理、行政处罚决定书、抽查合格名单。
> **先给结论**：恒源祥是**"卖吊牌"模式的典型**——自己不生产，上游授权工厂、下游授权经销商，2007 年商标使用费就占公司收入 80% 以上。结果是：**同一块牌子，工厂不同、好坏差很远**。已有硬证据：2015 年国家质检总局网售蚕丝被专项抽查中，标称丹阳市雅乐家纺生产的"恒源祥"蚕丝空调被 **pH 值 + 填充物品质不合格**；2013 年京东旗舰店一款"十孔蚕丝被"**实测蚕丝只占 20%**，根本达不到"蚕丝被"的 50% 门槛。**它合格的那些款，往往是爱伦、红柳这类正规大厂代工的。**

## 一、抽检与处罚硬证据

| 时间 | 抽查 / 案件 | 涉事产品 | 不合格项 |
| ---- | ---- | ---- | ---- |
| **2015-11** 国家质检总局网售蚕丝被专项抽查 | 「恒源祥」**蚕丝空调被**，标称生产：丹阳市雅乐家纺有限公司 | **pH 值、填充物品质**（当批 pH 16 批不合格＝安全问题；填充物品质 10 批＝短丝棉冒充长丝棉） |
| **2014-08** 辽宁省工商局 107 种床品抽检 | 「恒源祥」**全棉印花四件套**，标称生产：江阴市红柳被单厂有限公司 | **耐碱汗渍色牢度** |

**2015 年那条的两个词要点**：
- **pH 值不合格**是安全项，贴身用可能刺激皮肤（面料/胎套染整后碱性残留）。
- **填充物品质不合格**＝用短丝棉冒充长丝棉——这直接决定盖两年就板结。

## 二、最该记住的一个案例：名字叫"蚕丝被"，蚕丝只占 20%

2013 年人民网报道：消费者在京东"**恒源祥家纺旗舰店**"买「**十孔蚕丝被**」，原价 1398 元、促销 499 元；收到后查国标发现——合格证填充料写的是「**64% 聚酯纤维、16% 聚酯纤维（十孔纤维）、20% 柞蚕丝**」。

- 国标定义：填充物含桑蚕丝和/或柞蚕丝 **50% 及以上**才能叫蚕丝被。**20% 蚕丝 = 不是蚕丝被**，只是化纤被。
- 结果：消费者投诉后获得"**假一赔一**"；商家随后把商品名从"十孔蚕丝"改成"**20% 蚕丝**"。
- 这条是"什么牌子、什么东西、不能买"最典型的样本：**化纤为主 + 少量柞蚕丝，套上"蚕丝"两个字卖**。

## 三、模式决定了风险：它不生产，只授权

- 1991 年起走"联合体模式"：上游授权工厂、下游授权经销商；**2007 年营业额 3 亿、商标使用费 2.66 亿，占收入 80% 以上**（36 氪、央视网报道口径）。
- 央视网/南方周末报道的行业调查：线上经销商"**默许从市场组货**，前提是与工厂达成合作、**以工厂的名义领取吊牌**"；品牌方要求授权工厂提供质检合格证，而"合格证淘宝上 100 元就能买到"。
- 所以判断恒源祥不能看牌子，只能看**这一件的标称生产单位 + 吊牌实测标注**。

## 四、反向事实（合格的那些长什么样）

| 时间 | 抽查 | 恒源祥样品 | 结果 |
| ---- | ---- | ---- | ---- |
| 2017 年第 3 季度 江苏省级（85 批 88.2%） | 「冰沁蚕丝被」200×230、填充 1000g，苏州人民商场；标称生产 **江苏爱伦家纺** | **合格** |
| 2021 年 苏州市级（第 76 期） | 「桑蚕丝冬被」200×230、填充 2000g，吴江润泰商业；标称生产 **上海恒源祥家用纺织品** | **合格** |
| 2023 年 中宁县纤维制品抽检 | 「恒源祥」大豆纤维被 200×230 合格品 | **合格**（非蚕丝被） |

规律很清楚：**标称生产是正规大厂（爱伦、红柳、恒源祥自身体系）的款，能过；标称生产是小厂/加盟厂的款，出问题的都在这类**。

## 五、不能买 / 要少买

1. **名字带"蚕丝"但标注蚕丝含量低于 50% 的**——"十孔蚕丝被""蚕丝棉被""蚕丝绒被""蚕丝混合被"，先看合格证的填充料百分比，**蚕丝不到 50% 就不叫蚕丝被**。
2. **柞蚕丝冒充桑蚕丝的款**：柞蚕丝便宜得多、偏黄偏硬，2015 年那批里"以柞蚕丝冒充桑蚕丝"就是主要不合格原因之一。
3. **标称生产单位是陌生小厂/加盟厂的促销款**：恒源祥绝大多数不合格都出在加盟工厂。
4. **拼多多/非授权店的"恒源祥"**：2025 年就有**加盟商自己买假商标标识贴牌卖**（罚 1.2 万、没收吊牌 230 只）；只认天猫/京东"恒源祥家纺旗舰店"与授权门店，收到货核防伪。
5. **只给你看"质检合格证"复印件的店铺**：行业报道里这类证 100 元可买；要看**带批号的检测报告**（能对上你这件的货号/生产日期）。
6. **低于原料价的"桑蚕丝被"**：长丝绵原料约 300 元/斤，2 斤填充的"499 元桑蚕丝被"——按 2013 年那款的结构，基本是化纤+少量柞蚕丝。

## 六、三条验货

1. **先看合格证填充料百分比**：桑蚕丝含量、柞蚕丝含量、聚酯纤维含量，三项分开写才算规范；总蚕丝 <50% 直接放弃。
2. **拉检测口掏中间层**：短丝棉冒充长丝棉是它 2015 年被点的项——一扯就断、丝路乱的不要。
3. **核标称生产单位**：吊牌"生产企业"是不是正规大厂（爱伦、红柳、恒源祥家纺体系）；是陌生小厂且价格异常低，按加盟厂风险对待。
