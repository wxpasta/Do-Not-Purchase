# 罗莱（罗莱生活 LUOLAI）：哪些不能买

> 口径：黑龙江工商局 2017 年流通领域抽检、广州市消委会 2018 年比较试验、江苏/苏州抽查原始名单、公司公告。
> **先给结论**：罗莱是这批里**抽检表现最稳的一家**——2018 年广州市消委会 61 款蚕丝被比较试验中，罗莱是"通过所有项目测试"的 20 款之一；2017 年江苏省级抽查三款全合格；2021 年苏州抽查罗莱儿童冬被合格。它唯一一次上黑榜是 **2017 年黑龙江工商局抽检的一款"天丝蚕丝被"，纤维含量（面料、填充物）不合格**，而**罗莱回应称该商品并非其生产**——这条恰好说明它最大的风险不是厂里，是**渠道（非授权摊位、直播尾货、电商专供子品牌）**。

## 一、唯一一次黑榜：2017 年黑龙江，且公司否认是自己生产

| 项目 | 内容 |
| ---- | ---- |
| 抽查 | 2017-11-16 黑龙江省工商局 流通领域商品质量抽查检验不合格名单 |
| 样品 | 标称商标「LUOLAI」，标称生产者「罗莱家纺股份有限公司」，**天丝蚕丝被 150cm×200cm**，货号 750 |
| 经营者 | **爱辉区东方床上用品摊床**（边境城市黑河的摊位，非授权门店） |
| 不合格项 | **纤维含量——面料、填充物**（业内解读：吊牌标称成分与实际不符） |
| 公司回应 | **该商品并非由罗莱生产**（北京商报报道原话："难道遇上'李鬼'了"） |

**这条的正确定性**：不能据此说"罗莱蚕丝被掺假"——公司否认生产，问题指向**冒牌货/串货进了非授权摊位**。但它给出一个非常实用的结论：**买罗莱必须认渠道**，摊位货、尾货、直播清仓的"罗莱"，连公司自己都不认。

| 时间 | 抽查 | 罗莱样品 | 结果 |
| ---- | ---- | ---- | ---- |
| 2018 年 广州市消委会 61 款比较试验（仅 20 款全项通过） | 商场/专卖店/电商随机购样 | 罗莱 | **通过所有项目测试**（与富安娜、雅芳婷等同列 20 款） |

| 2021 年 苏州市级（第 76 期） | 罗莱儿童「全棉双层抗菌蚕丝冬被」2000g，苏州天虹 | — | **合格** |

## 三、品牌矩阵复杂，买前先分清

罗莱生活旗下自有品牌：**罗莱/LUOLAI、罗莱儿童、LOVO 乐蜗（互联网渠道专供，欧睿口径 2019–2021 中国互联网床上用品第一）、LAVIE HOME 廊湾**；另有代理品牌 SHERIDAN、ZUCCHI、bassetti、GRACCIOZA、sorema、iittala、DURANCE、MILLEFIORI 等。

- **多品牌、多价带**意味着同名不同质：同一集团里，LOVO 主打线上性价比，规格、克重、面料配置与线下"罗莱"专柜款不是一套 SKU。
- 官网口径"罗莱床上用品连续 21 年市场综合占有率第一"的统计来源是**中华全国商业信息中心"全国重点大型零售企业"**——**线下零售口径，不含电商**，别当成全渠道销量第一。

## 四、不能买 / 要少买

1. **非授权渠道的"罗莱"**：摊位货、边境口岸货、直播清仓尾货——2017 年那件就出在摊位，公司直接否认生产。只认专柜/官方旗舰店，并核防伪。
2. **"天丝蚕丝被""莱赛尔蚕丝被"这类复合命名**当纯蚕丝被买：天丝/莱赛尔是**面料**（再生纤维素纤维），填充才是蚕丝；看清"面料成分"和"填充物成分"两栏，别混。
3. **电商专供款（LOVO 等）与线下款混着比价**：同价不同克重/不同面料是常态，比价必须比"净重 + 丝绵长度 + 面料成分"，不是比标价。
4. **"好礼免费领"邮寄广告/扫码领罗莱产品**：罗莱 2024-07 自己发过声明——有人冒用罗莱名义邮寄虚假广告，扫码后并非免费领产品。这类链接不点。
5. **儿童款不看安全类别**：罗莱儿童 2021 年苏州抽查合格那款是"全棉双层抗菌蚕丝冬被"，给孩子买认 **GB 31701 A 类**（婴幼儿及儿童纺织产品安全技术规范），只标 GB 18401 B 类的不适合贴身婴幼儿。
6. **把集团层面的监管记录当产品质量问题**：2024 年江苏证监局对罗莱生活出具**警示函**、深交所出具**监管函**（事由是董事辞职披露不实、董事会参会人数与表决情况披露不符、时任董事被留置未及时披露）——**属信息披露违规，与产品无关**，别混。

## 五、三条验货

1. **认渠道**：专柜/官方旗舰店 + 防伪码；摊位、尾货、代购一律按风险对待。
2. **拆两栏看标注**：面料成分（棉/天丝/聚酯纤维）与填充物成分（桑蚕丝/柞蚕丝 + 丝绵长度 + 净重）分开核对；总蚕丝 <50% 不叫蚕丝被。
3. **拉检测口掏中间层**：连续长丝才算长丝绵；短丝、丝路乱的是低档。
