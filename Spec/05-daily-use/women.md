# 女性用品：哪些不能买 / 少买

> 口径：只收**药监局抽检通告、市监局监督抽查、卫健/疾控抽检、消协比较试验、行政处罚决定书**里点名到品牌或型号的条目。
> 一句话：女性用品最容易翻车的三处——**卫生巾全长偏差、防晒/染发的"成分比对"、私处洗液偷偷加激素**。

## 一、卫生巾 / 护垫

| 品牌 / 批次 | 什么产品 | 结论 | 一句话原因 |
| ---- | ---- | ---- | ---- |
| 曲美（天津和顺达卫生用品）夜用 420mm×12 片，批号 2025/11/02 | 卫生巾 | 不能买 | 天津蓟州市监处罚〔2026〕58 号：**全长偏差**不符 GB/T 8939—2018，现场查封 540 包，立案查处 |
| 棉密码 | 卫生巾 | 不能买 | 检出致癌物硫脲超标约 16 倍（详见 [daily-items.md](daily-items.md)） |
| 淘淘氧棉 天山白系列夜用（桂林洁伶工业） | "国标消毒级"卫生巾 | 少买（待官方定性） | 2026.07 消费者拆封发现黑点与虫体；桂林七星区市监局已现场核查并抽检同款，**尚未见抽检结论** |
| 不分牌子：只写"消毒级""医护级"、不标执行标准的 | 卫生巾 | 不能买 | 卫生巾按 GB 15979—2024 + GB/T 8939—2018；"消毒级"不是药，别为标签溢价 |

抽查不合格率参考（不点名但要心里有数）：辽宁 2026 年卫生巾专项，流通领域 19 批次 1 批次不合格、生产领域 6 批次 1 批次不合格；厦冂 2026 年抽 15 批次、8 家流通企业。

## 二、内衣 / 文胸

| 品牌 | 什么产品 | 结论 | 一句话原因 |

| 娜彤蜜 | 塑身内衣 | 少买 | 同次试验：色牢度偏弱，有掉色、串色风险（贴身衣物掉色会沾皮肤） |
| CAMEL、雪茜曼、HORMOVE ACTIVE | 运动内衣 | 少买 | 耐汗渍色牢度偏弱，出汗多、频繁洗的场景扛不住 |
| 宇熙柔、特步 | 运动内衣 | 少买 | 5 次标准水洗后沾色不均 |
| UNDER ARMOUR、百分百感觉 | 运动内衣 | 少买 | 拉伸回复率仅 84.3%、81.3%，长期穿易变形、肩带松弛 |

| 山东 3 批次（销售者：聊城振华量贩民生广场店、张店区芬腾针织店、烟台初选服饰） | 内衣 | 不能买该批次 | 山东省局 2026"你点我查"：**甲醛含量、纤维含量**不合格 |

反向事实（别一刀切）：北京消协 80 款内衣 **pH 值全部合格**，其中 79 款达到 A 类（4.0–7.5），安全性能整体可靠；问题主要在**标注不实**和**色牢度**，不是"内衣都有毒"。

| 品牌 / 产品 | 不合格项目 | 结论 |
| ---- | ---- | ---- |
| 馥珮 水嫩璀璨精华水等 18 批次（2026 年第 42 号） | **检出禁用原料** | 不能买 |
| FLOWERWAY 童颜胶原蛋白灌注面膜（广州一可生物） | **菌落总数 + 铜绿假单胞菌** | 不能买（敷脸等于敷菌） |
| 百方堂 草本隔离霜（广东御芳泽） | 成分比对 | 不能买 |
| 美琦诗 染发膏-深梨木色（广州美奇丝/海露，2 批次） | 成分比对 | 不能买（染发剂成分与标示不符） |
| 天峰本草护理染发霜 M4（浙江章华） | 成分比对 | 不能买 |
| ICE LOVE 轻透倍护防晒乳 SPF50+ PA++++（广东俏美人，2 批次） | 成分比对 | 不能买（标的防晒剂没加够 = 白晒） |
| 雪贝雅、即尚、BROLAMEN 柏兰梦 美白隔离防晒乳 | 成分比对 | 不能买 |

| COAROO、韩维妮（广东雅威）、珀蜜思防晒喷雾、卡莉莱、欧美莲 美白防晒 | 成分比对 | 不能买 |
| 形象美 凝润补水芦荟胶（广州爱莲） | 菌落总数 | 不能买 |
| 迪悦朵、TJE 防晒（广州名秀/合盛） | 防晒剂成分**漏加或标错**（多个 UV 吸收剂不符） | 不能买 |

**"成分比对"到底多严重**：防晒乳标 SPF50、PA++++ 却没加对应防晒剂，等于花钱买了个"心理防晒"；染发膏同理，标称的色号成分对不上。这类不合格在药监局通告里占比最高。

## 四、私处洗液 / "消字号"护理品

| 对象 | 事实 | 结论 |
| ---- | ---- | ---- |
| 南宁 2026 抗（抑）菌制剂专项抽检 11 份 | 1 份检出**硝酸咪康唑 + 氯倍他索丙酸酯**（抗真菌药 + 强效激素），合格率 90.91%，已责令下架召回销毁 | 风险真实存在，非个案 |
| 广西玉林某消毒产品企业 | 三款抑菌乳膏检出氯倍他索丙酸酯/硝酸咪康唑等禁用物质，21 款产品未备案，**被吊销卫生许可证** | 不能买同类产品 |
| 不分牌子：写"治疗妇科炎症""抗炎消炎""缓解瘙痒""X 天为一疗程"的洗液/凝胶 | 违反《消毒产品标签说明书管理规范》，属违法宣传 | 不能买 |

选购四条：
1. 全国消毒产品网上备案信息服务平台查产品名、企业、标签是否一致，**没备案的不买**；
2. 2025.05.01 起抗（抑）菌制剂必须印"**本品不是药品，不具有治疗、护理、保健作用**"，没这句的不合规；
3. 用于阴部黏膜的产品必须印"**不应用于性生活中对性病的预防**"，且不得写"适用于破损皮肤/黏膜"；
4. 私处不需要"杀菌护理"，日常清水或弱酸洗液足够；激素类洗液长期用会致激素依赖性皮炎、色素沉着。

## 五、五条记住

1. 卫生巾看**执行标准**（GB 15979—2024 + GB/T 8939—2018）和**实际长度**，别买"消毒级"话术；
2. 内衣先看**吊牌纤维含量**，实测不符是这批抽查的头号问题；贴身衣物色牢度差会掉色沾皮肤；
3. 防晒只认**药监局备案 + 成分表**，通告里"成分比对"不合格的牌子直接跳过；
4. 面膜看生产企业和备案号，菌落总数、铜绿假单胞菌不合格的都上过通告；
5. 私处洗液认"消字号备案"，出现"治疗、消炎、疗程"字样的，当药卖就是违规。
