# 少买——装修 / 家居避坑

> 口径：装修公司跑路、增项陷阱、全屋定制货不对板等消费者高频踩坑。
> 列定义：**品牌** = 装修公司 / 家居品牌名；**企业 / 涉事方** = 法人主体。

| 品牌 | 企业 / 涉事方 | 问题 | 事实 |
| ---- | ---- | ---- | ---- |
| 业之峰装修公司 | 业之峰装饰集团 | 全屋定制"无甲醛"家具实际超标 | 2024.09：河北固安消费者起诉，业之峰内部欧派店面卖的"无甲醛"家具甲醛超标；法院判业之峰按全屋定制价格二倍赔偿 72 万元 |
| 居然之家新塘店（广州增城） | 居然之家家居连锁集团 | 店内多品牌店"爆雷"，消费者维权扯皮 | 2025.06：顾家、欧铂尼、伊仕利、原川 4 家品牌店同时停业，数百户业主订单无法交付，涉及金额超千万元；爆雷前以"国补"诱导消费者一次性交全款 |
| 天地和装饰 | 天地和家装集团 | 全包暗藏增项 | 2019 315 曝光：宣传 1798 元/㎡ 全包豪华装修送家电家具，实际交完 35% 预算后增项一个接一个，最终总价远超预算 |

## 怎么避

1. **别一次性交全款**：不管装修公司怎么承诺"交全款送家电/打折"，最多交 30%-50%，留尾款验收后再付。
2. **看清"全包"包含什么**：很多"全包"只包基础施工，水电改造、墙面找平、防水都要额外加钱。
3. **全屋定制别信"无甲醛"**：只要用板材，就有甲醛，只是多少的问题。"零甲醛"是营销话术。
4. **居然之家/红星美凯龙里的店也会跑**：商场只是收租金的，里面的品牌店爆雷了，商场不一定管。
