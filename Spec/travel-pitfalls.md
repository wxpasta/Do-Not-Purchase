# 少买——出行 / 交通避坑

> 口径：网约车大数据杀熟、共享单车乱扣费、平台管理不到位等消费者高频踩坑。
> 列定义：**品牌** = APP / 平台名；**企业 / 涉事方** = 法人主体。

| 品牌 | 企业 / 涉事方 | 问题 | 事实 |
| ---- | ---- | ---- | ---- |
| 携程 | 上海携程商务有限公司 | 大数据杀熟 | 2026.10：最高法发布涉人工智能纠纷典型案例，携程"调价加价"案被判退一赔三——利用算法对老用户/高频用户实行差别定价 |
| 高德打车 | 高德软件有限公司（阿里巴巴旗下） | 对合作网约车平台管理不到位 | 2026.02：交通运输新业态协同监管部际联席会议约谈高德打车，指出存在压低运价、应急处置不当、司机权益保障不足等问题 |
| T3 出行 | 南京领行科技股份有限公司 | 司机违规加收费用 | 2026：郑州王先生乘 T3 网约车去新郑机场，司机违规加收 11 元高速费（实际政府已兜底，ETC 显示 0 元）；司机被罚 200 元 |
| 景区杂牌共享单车 | 各地小品牌共享单车运营商 | "单车刺客"，起步价畸高 | 2026.06：北京天安门/前门景区，林先生骑 16 分钟被收 50 元——起步价就 30 元，扫码前根本看不到完整价格 |

## 怎么避

1. **网约车多平台比价**：同一目的地，滴滴/高德/T3/花小猪 价格可能差很多，别只用一个 APP。
2. **新用户比老用户便宜**：大数据杀熟是行业潜规则，新账号往往比老账号便宜。
3. **共享单车扫码前看清楚价格**：景区/火车站附近的杂牌共享单车，起步价可能 15-30 元，别扫了就骑。
4. **高速费/停车费上车前说清楚**：下车前再核对账单，有问题当场提。
