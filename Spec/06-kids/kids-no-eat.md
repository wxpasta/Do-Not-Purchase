# 孩子别吃 / 少吃——牌子 + 东西 一页清单

> 只列"哪个牌子的什么产品"，不解释标准。要查依据看 [food-safety.md](../01-food/food-safety.md)。
> **不能吃** = 有抽检不合格、处罚、虚假标注、异物等实锤。
> **少吃** = 没被处罚但配方/成分对孩子不友好，或只是争议线索。

## 二、少吃（没实锤处罚，但别当日常）

| 牌子 | 什么东西 | 一句话原因 |
| ---- | ---- | ---- |
| 趣多多（亿滋） | 脏脏黑巧曲奇 | 代可可脂 ≥19%，包装正面不提示 |
| 好丽友 | 好丽友·派 | 中外配料表争议（国内含代可可脂），官方否认双标，无处罚结论 |
| 红牛（天丝） | 维生素牛磺酸饮料 | 泛酸不合格被罚 80 万；含咖啡因，孩子不喝 |
| 外卖店泰式奶茶 | 泰式奶茶 | 多批次检出日落黄超标 |
| 三只松鼠 | 山核桃味瓜子 | 霉菌不合格被罚 |
| 老干妈 | 油辣椒 / 腐乳 | 曾有苯甲酸超标、出口批次骨头碎片召回 |
| 寿司郎 | 门店餐食 | 一年内 13 次行政处罚，半数涉食品卫生 |
| 营养快线 / AD 钙奶 / 优酸乳 / 酸酸乳 | 乳饮料 | 水+糖+香精，不是奶 |
| 早餐奶 / 核桃奶 / 巧克力奶 | 调制乳 | 加糖加香精，不是纯牛奶 |
| 养乐多 / 优乐多 | 乳酸菌饮料 | 糖多、菌少 |

## 三、记住三条

1. 冰棍、雪糕、蜜饯、饮料：**没听过的杂牌 + 便宜 + 散装，一律不买**。
2. 巧克力：包装写"代可可脂"的不买；只写"巧克力/黑巧"却不写可可脂的，翻配料表。
3. 写着"奶"的饮料：配料表第一位不是"生牛乳"的，就是甜饮料。
