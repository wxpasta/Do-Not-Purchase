# 认知校准——原外国品牌，现被中资收购 / 运营

> 这一类不是"不要买"，而是**别再按"洋品牌"为它付溢价**。很多品牌还在打"德国工艺""日本品质""瑞典豪华"的旧人设，但股权、研发决策权、供应链都已经是中国公司的了。买前认清归属，按国产同类比价即可。
>
> **分两种情况，别混为一谈：**
> - **模式 A：品牌所有权真被中资买走**（商标归中资）——沃尔沃、ThinkPad、东芝白电、GE 家电、MG 名爵。
> - **模式 B：中资拿到运营权/特许经营权**（商标仍是洋牌，中资只是被授权方）——麦当劳中国（金拱门）、星巴克中国（博裕合资）、百胜中国（肯德基/必胜客）。这种最容易被误以为"已经是中国品牌"，其实不是。

## 一句话识别

- 包装/官网还在强调"原 XX 国技术""XX 国原装"，但"股权结构"一栏已经写的是中国公司。
- 电商详情页"进口"字样慢慢换成"合资"，价格却还是洋品牌定价。
- 财报里研发费用、工厂位置都在国内，但营销话术仍主打"海外血统"。

## 特别注意：运营权在中资、品牌仍是洋牌（最容易被误认成"中国品牌"）

这三家是用户最常误以为"已经是中国品牌"的，但法律上**商标/知识产权仍归美国总部**，中资拿的是运营权/特许经营权，不是品牌所有权：

| 品牌 | 运营主体 | 股权结构 | 关键事实 |
| ---- | ---- | ---- | ---- |
| 麦当劳（中国内地/香港/澳门） | 金拱门（中国）有限公司 | 中信联合体（信宸资本/中信资本）控股约 52%，麦当劳全球约 48%（2023 年从 20% 增持） | 1. 2017.01 中信联合体以最高 20.8 亿美元收购麦当劳中国业务；金拱门是麦当劳在美国以外最大的特许经营商<br/>2. 麦当劳品牌仍是美国麦当劳公司所有，金拱门只是被授权方<br/>3. 2024.10 中信股份把 19.23% 股份转给中信资本旗下信宸资本 |
| 星巴克（中国内地） | 星巴克咖啡（中国）合资公司 | 博裕投资基金持股 60%，星巴克全球持股 40% | 1. 2025.11 公布合作意向，2026.04.02 正式交割，估值约 40 亿美元<br/>2. 星巴克全球继续作为品牌与知识产权的所有者和授权方<br/>3. 这是星巴克 2017 年实现中国区 100% 控股、全部直营后，再次转向合资经营 |
| 肯德基 / 必胜客 / 塔可钟（中国） | 百胜中国控股（Yum China） | 独立上市公司，纽交所 + 港交所双重主要上市；注册地美国特拉华州，总部上海 | 1. 2016.11.01 从美国百胜集团（Yum! Brands）分拆独立上市，不是被中资收购<br/>2. 拥有肯德基、必胜客、塔可钟等品牌在中国的独家运营和再授权权，每年向原母公司支付特许经营费<br/>3. 股东是公开市场投资者（含机构和个人），不是某个中国公司控股 |
