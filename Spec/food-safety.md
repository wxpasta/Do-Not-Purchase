# 少买——食品安全问题

> 口径：有监管抽检不合格、官方召回、媒体调查实锤的食安问题。非永久抵制，是"买前心里有数"。
>
> 列定义：**品牌** = 消费者能直接看到的名字；**涉事企业** = 法人主体或代工厂。

| 品牌 | 涉事企业 | 问题 |
| ---- | ---- | ---- |
| 老干妈 | 贵阳南明老干妈风味食品有限责任公司 | 1. 2007：天津市场监管抽检，红油腐乳苯甲酸超标，责令下架处罚<br/>2. 2020：澳洲食品标准局召回出口批次产品，检出骨头碎片风险 |
| 麦当劳 / 肯德基 / 必胜客 / 汉堡王 / 棒约翰 / 德克士 / 7-11（终端品牌） | 上海福喜食品有限公司（OSI 集团旗下，代工厂） | 2014 福喜过期肉事件：<br/>1. 2014.07：东方卫视卧底 2 个月曝光，上海福喜将过期 8 个月、颜色发青的臭肉重新切片装新包装，"保质期"延长 1 年；央视《焦点访谈》跟进报道<br/>2. 涉事客户共 9 家连锁企业<br/>3. 2016：福喜认罚 1698 万元，被纳入黑名单 |
| 星巴克 | 上海星巴克咖啡经营有限公司（无锡震泽路店、无锡昌兴大厦店） | 门店篡改保质期、使用过期食材：<br/>1. 2021.12：媒体曝光两店篡改、撤换、撕毁食品原料保质期标签；无锡市市场监管局行政约谈星巴克中国华东北区<br/>2. 2022.02：无锡市新吴区市场监管局对两店合计罚没约 140 万元（震泽路店约 69 万、昌兴大厦店约 67 万） |
